# 학습: DFS (깊이 우선 탐색)

> 관련 문서: [학습_BFS](../problems/programmers/lv2/006_게임_맵_최단거리/학습_BFS.md)

이 문서는 지금까지 여러 문제에서 반복해 써 온 **DFS(재귀 탐색)** 를 한자리에 모아 정리한 것입니다.
계단 오르기부터 단어 변환까지, **모양은 조금씩 달랐지만 골격은 같은 하나의 도구**였다는 것을 확인하는 게 목표입니다.
예제는 전부 여러분이 **직접 통과시킨 코드**를 그대로 인용합니다(딱 하나, `네트워크`만 예제로 공개된 답안입니다).

---

## 1. DFS란 무엇인가

DFS는 **한 길로 갈 수 있는 데까지 끝까지 파고들었다가, 막히면 되돌아와 다른 길을 트는** 탐색입니다.

- 미로에서 한쪽 벽만 잡고 갈림길마다 **일단 한 방향으로 끝까지** 걸어갑니다.
- 막다른 길(더 갈 곳 없음)을 만나면 **직전 갈림길로 되돌아와** 아직 안 가 본 다른 방향을 잡습니다.
- 이 "끝까지 갔다가 되돌아옴"을 대신해 주는 것이 바로 **재귀 호출**입니다.

### 재귀 호출 스택 = "지금 걸어온 길"

`dfs(a)` 안에서 `dfs(b)` 를 부르면, `a`는 아직 안 끝난 채로 잠시 멈추고 `b` 안으로 들어갑니다.
`b`가 끝나면 **자동으로 `a`로 돌아와** 멈췄던 다음 줄부터 이어갑니다.

이때 "부르고 아직 안 끝난 함수들"이 쌓인 것이 **호출 스택**이고, 이 스택이 곧 **지금 내가 걸어온 경로**입니다.
막다른 길에서 `return` 하는 것이 곧 **되돌아옴(back)** 입니다. 우리는 스택을 직접 만들지 않아도, 재귀가 알아서 스택 역할을 해 줍니다.

### BFS와의 대비

같은 "그래프를 전부 훑는다"는 목표라도 방문 순서가 정반대입니다. ([학습_BFS](../problems/programmers/lv2/006_게임_맵_최단거리/학습_BFS.md) 참고)

| | DFS (깊이 우선) | BFS (너비 우선) |
|---|---|---|
| 한 마디로 | **한 길로 끝까지** 파고들었다 되돌아옴 | **가까운 것부터 한 겹씩** 넓게 퍼짐 |
| 비유 | 미로에서 한쪽 벽 잡고 끝까지 걷기 | 연못에 던진 돌의 **물결(파문)** |
| 담아두는 도구 | **스택** (재귀 호출이 곧 스택) | **큐** (`deque`) |
| 되돌아옴 | 있음 (막히면 back) | 없음 (앞으로만 퍼짐) |

이 문서는 DFS의 여러 **모양**을 하나씩 짚어 나갑니다. 모양은 달라도 골격("한 곳에서 이웃으로 재귀, 막히면 return")은 전부 같습니다.

## 2. 모양 1: 누적형 vs 반환형

같은 DFS라도 **답을 어디에 모으느냐**로 두 갈래가 있습니다. 여러분의 학습은 누적형에서 시작해 반환형으로 넘어갔습니다.

### 누적형 (nonlocal 로 바깥 변수에 쌓기)

`부분_수열의_합`에서 쓴 방식입니다. 바깥에 `answer`를 두고, 성공할 때마다 `nonlocal`로 그 변수를 직접 늘립니다.

```python
def solution(nums, target):
    n = len(nums)
    answer = 0

    def dfs(i, cur_sum):
        nonlocal answer
        if i == n:
            if cur_sum == target:
                  answer += 1
            return
        dfs(i + 1, cur_sum + nums[i])
        dfs(i + 1, cur_sum)

    dfs(0, 0)
    return answer
```

- `answer`는 재귀 바깥에 **한 개**만 있고, 모든 가지가 그 하나를 공유하며 값을 더합니다.
- `nonlocal answer` 는 "이 `answer`는 새로 만들지 말고 **바깥 것을 쓰겠다**"는 선언입니다. 이게 없으면 `answer += 1`이 함수 안의 새 지역변수를 만들려다 오류가 납니다.

### 반환형 (자식의 답을 return 으로 받아 합치기)

`타겟_넘버`에서 넘어간 방식입니다. 바깥 변수 없이, **각 재귀가 자기 몫의 답을 `return`** 하고, 부모가 그것을 받아 합칩니다.

```python
    n = len(numbers)
    def dfs(i, tot):
      if i == n:
        return 1 if tot == target else 0
      return dfs(i + 1, tot + numbers[i]) + dfs(i + 1, tot - numbers[i])
    return dfs(0,0)
```

- 끝(`i == n`)에 닿으면 성공이면 `1`, 실패면 `0`을 **돌려줍니다**.
- 부모는 `dfs(...) + dfs(...)` 로 두 자식이 돌려준 값을 **더해서** 다시 위로 올립니다.
- `nonlocal`도, 바깥 `answer`도 필요 없습니다. 답이 재귀의 반환값을 타고 자연스럽게 위로 모입니다.

### 둘의 관계

가장 처음 푼 `계단_오르기`도 지금 코드는 반환형입니다(처음엔 nonlocal 누적으로 풀었고, 이후 반환형으로 개선한 문제입니다). "여기서 도착까지 가는 방법의 수"를 각 재귀가 돌려주고 부모가 더합니다.

```python
    def dfs(cnt):
      # 결과 조건 먼저
      if cnt == n:
        return 1
      elif cnt > n:
        return 0
      return dfs(cnt + 1) + dfs(cnt + 2)

    return dfs(0)
```

> **정리:** 누적형은 "바깥 통에 하나씩 담기", 반환형은 "자식이 준 답을 받아 합쳐 올리기".
> 둘 다 세는 결과는 같습니다. 반환형이 바깥 상태가 없어 더 깔끔한 경우가 많고, 뒤에 나올 **집계 방법**(4·6절)과도 자연스럽게 이어집니다.

## 3. 모양 2: 갈래 나누기 (완전탐색)

"각 원소마다 **선택지를 모두** 재귀로 뻗는다"가 완전탐색 DFS의 공통 골격입니다. 원소 하나를 처리할 때마다 갈래가 갈리고, 그 아래로 다시 갈래가 갈려 **모든 경우**가 빠짐없이 만들어집니다.

### 타겟_넘버 — +/− 두 갈래

각 숫자 앞에 `+`를 붙일지 `-`를 붙일지, 원소마다 2갈래로 뻗습니다.

```python
      return dfs(i + 1, tot + numbers[i]) + dfs(i + 1, tot - numbers[i])
```

- 왼쪽 `dfs(i+1, tot + numbers[i])` = "이번 원소를 **더하는**" 세계
- 오른쪽 `dfs(i+1, tot - numbers[i])` = "이번 원소를 **빼는**" 세계
- 두 세계를 모두 열어 끝까지 내려가면, 원소 n개의 부호 조합 $2^n$ 가지가 전부 탐색됩니다.

### 부분_수열의_합 — 넣는다 / 뺀다 두 갈래

이번엔 각 원소를 **고를지 말지** 2갈래입니다.

```python
        dfs(i + 1, cur_sum + nums[i])   # i번째를 고르는 경우
        dfs(i + 1, cur_sum)             # i번째를 안 고르는 경우
```

- 위 = "이 원소를 조합에 **넣는다**"
- 아래 = "이 원소를 **뺀다**(안 넣는다)"
- `+/−`든 `넣는다/뺀다`든 **이름만 다를 뿐 골격이 같습니다**: 원소마다 선택지를 전부 재귀로 열고, `i+1`로 다음 원소에 넘긴다. 끝(`i == n`)에서 판정한다.

> **공통 골격 한 줄 요약:** `dfs(i)` 안에서 **선택지 수만큼 `dfs(i+1)` 을 부르고**, 마지막 원소까지 갔을 때(`i == n`) 성공 여부를 따진다.

## 4. 모양 3: 방문 표시와 되돌리기

앞의 완전탐색은 원소를 **순서대로 한 번씩** 처리했습니다. 그런데 `이어붙여_만든_수`처럼 **순서를 바꿔 가며 모든 배열(순열)** 을 만들어야 하면, "이번 가지에서 이미 쓴 원소"를 표시해 두고, 그 가지를 빠져나올 때 **표시를 되돌려야** 합니다.

```python
def solution(digits):
    n = len(digits)
    used = [False] * n
    made = set()                     # 만든 수를 담을 집합(중복 자동 제거)

    def dfs(cur):                    # cur = 지금까지 이어붙인 문자열
        for i in range(n):
            if used[i]:
                continue
            used[i] = True
            nxt = cur + str(digits[i])   # i를 뒤에 이어붙임
            made.add(int(nxt))           # 이 시점의 수를 집합에 추가
            dfs(nxt)                     # nxt를 들고 더 깊이
            used[i] = False              # 되돌리기

    dfs("")                          # 빈 문자열에서 시작
    return len(made)                 # 서로 다른 수의 개수
```

### 왜 `used[i] = False` 로 되돌려야 하는가

`used[i] = True` 는 "**지금 걸어가는 이 길에서** i를 이미 썼다"는 뜻입니다. 그런데 i는 **다른 가지에서는 다시 쓸 수 있어야** 합니다.

예를 들어 원소가 `[3, 5]` 라면 우리는 `35`와 `53` 둘 다 만들어야 합니다.

```
dfs("")
 ├─ 3을 씀 (used[0]=True) → dfs("3") → 5를 씀 → "35"        ← 이 가지
 │                          여기서 빠져나오며 used[0]=False 로 되돌림
 └─ 5를 씀 (used[1]=True) → dfs("5") → 3을 씀 → "53"        ← 3을 또 써야 함!
```

만약 첫 번째 가지에서 `used[0]=True`로 켜 놓고 **되돌리지 않으면**, 두 번째 가지로 갔을 때 "3은 이미 썼다"고 오해해 `53`을 못 만듭니다.
그래서 `dfs(nxt)`가 끝나 **그 가지에서 완전히 빠져나온 직후** `used[i] = False`로 꺼서, 형제 가지가 i를 깨끗한 상태에서 다시 쓸 수 있게 합니다.

> **핵심:** 방문 표시가 "**이 길에서만** 유효"해야 할 때는, 그 길을 빠져나오며 표시를 원상복구합니다.
> (뒤에 나오는 격자·그래프 문제처럼 "한 번 방문하면 영영 방문"인 경우엔 되돌리지 않습니다 — 5절에서 대비됩니다.)

## 5. 모양 4: 그래프 위의 DFS

지금까지는 "숫자 배열"을 훑었지만, DFS의 진짜 무대는 **그래프**입니다. 그런데 재미있는 점은, **그래프의 표현 방식만 바뀔 뿐 DFS 골격은 똑같다**는 것입니다.

골격은 언제나 이렇습니다.

```
dfs(현재):
    현재를 방문 처리
    for 이웃 in 현재의 이웃들:
        아직 안 갔으면 dfs(이웃)
```

바뀌는 건 딱 하나, **"이웃을 어떻게 찾느냐"** 뿐입니다.

| 표현 방식 | 예제 문제 | 이웃을 찾는 방법 | 방문 처리 |
|---|---|---|---|
| **격자(grid)** | 섬의 개수 / 가장 큰 섬 | **상·하·좌·우 4방향** 좌표 | 칸을 `0`으로 덮어씀(in-place) |
| **인접 행렬** | 네트워크 (📎 예제) | `for j in range(n): if computers[i][j] == 1` | `visited[j]` 배열 |
| **암시적 그래프** | 단어_변환 | **술어 함수**로 이웃 판정(`can_change_word`) | `selected_words` 목록 |

### 격자 — `섬의 개수`

이웃 = 상하좌우 4칸. 방문한 땅은 `0`으로 덮어 다시 안 밟게 합니다.

```python
    def grid_range_check(r,c):
      return 0 <= r and r < len(grid) and 0 <= c and c < len(grid[0]) and grid[r][c] != 0

    def dfs(r,c):
      grid[r][c] = 0

      for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
          if grid_range_check(r+dr, c+dc) == True:
            dfs(r + dr, c + dc)
```

`for dr, dc in ((1,0),(-1,0),(0,1),(0,-1))` 가 곧 "이웃 4방향"입니다. 경계 밖·바다는 `grid_range_check`가 걸러 냅니다.

### 인접 행렬 — `네트워크` (📎 예제로 공개된 답안)

이웃 = `computers[i][j] == 1` 인 `j` 들. 4방향 좌표 대신 **한 행을 통째로 스캔**합니다.

```python
def solution(n, computers):
    visited = [False] * n

    def dfs(i):
        visited[i] = True
        for j in range(n):
            if computers[i][j] == 1 and not visited[j]:
                dfs(j)          # 격자의 dfs(r+dr, c+dc) 자리

    cnt = 0
    for i in range(n):          # 격자의 이중 for문 → 여기선 단일 for
        if not visited[i]:      # 아직 방문 안 한 컴퓨터를 만나면
            cnt += 1            # 새 네트워크 하나 발견
            dfs(i)
    return cnt
```

격자의 `dfs(r+dr, c+dc)` 자리가 그대로 `dfs(j)` 로 바뀌었을 뿐, 나머지 골격은 판박이입니다. 이 골격을 여러분은 `가장_큰_네트워크`·`네트워크_크기_목록`에서 직접 통과시켰습니다.

### 암시적 그래프 — `단어_변환`

여기선 이웃 목록이 **미리 주어지지 않습니다.** 대신 "한 글자만 다르면 이웃"이라는 **규칙(술어 함수)** 으로 그때그때 이웃을 판정합니다.

```python
    def can_change_word(a,b):
        cnt = 0
        for i in range(len(a)):
            if a[i] != b[i]:
                cnt += 1
            if cnt == 2:
                return False
        return True

    def dfs(i,cnt, selected_words):
        if words[i] == target:
            return cnt
        best = sys.maxsize
        for j in range(len(words)):
            if can_change_word(words[i],words[j]) and words[j] not in selected_words:
                best = min(best, dfs(j,cnt + 1,[*selected_words, words[j]]))
        return best
```

`computers[i][j] == 1` 이 `can_change_word(words[i], words[j])` 로 바뀐 것 뿐입니다. **"연결됐는가?"를 배열에서 읽느냐, 함수로 계산하느냐**의 차이일 뿐, 이웃을 훑어 재귀로 들어가는 골격은 동일합니다.

> **통찰:** 격자든, 인접 행렬이든, 규칙으로 정의된 암시적 그래프든 — DFS가 하는 일은 언제나 "**현재의 이웃을 훑어 안 가 본 곳으로 재귀**"입니다. **"이웃을 찾는 방법"만 갈아 끼우면** 같은 골격이 그대로 굴러갑니다.

## 6. 집계 방법 3종 정리

DFS가 여러 가지로 뻗어 나가며 얻은 답들을 **어떻게 하나로 모으느냐**도 문제마다 달랐습니다. 세 가지로 정리됩니다.

| 집계 | 연산 | 중립값(시작값) | 대표 예제 |
|---|---|---|---|
| **개수 세기** | `+1` | `0` | 섬의 개수, 네트워크 (연결 요소 수) |
| **합치기** | `+=` | `0` | 가장 큰 섬의 넓이(`area = 1 + 사방 합`) |
| **최솟값** | `min` | **무한대(`sys.maxsize`)** | 단어_변환 (최소 변환 횟수) |

### 개수 세기 (+1)

바깥에서 새 덩어리를 만날 때마다 `cnt += 1`. `섬의 개수`·`네트워크`가 이 방식입니다.

### 합치기 (+=, 중립값 0)

`가장_큰_섬`의 넓이 집계. 자기 칸 `1`에 사방 자식들이 돌려준 넓이를 더해 올립니다.

```python
    def dfs(r,c):
      grid[r][c] = 0
      area = 1

      for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        if grid_range_check(r + dr, c + dc) == True:
          area += dfs(r + dr, c + dc)
      return area
```

`area`의 시작값 `1`은 자기 자신, 여기에 자식들의 넓이를 `+=` 로 합칩니다(반환형, 2절 참고).

### 최솟값 (min, 중립값 무한대)

`단어_변환`의 최소 변환 횟수. 여러 가지 중 **가장 짧은** 것을 골라야 하므로 `min`으로 경쟁시킵니다.

```python
        best = sys.maxsize   # "아직 성공한 가지 없음" = 무한대
        for j in range(len(words)):
            if can_change_word(words[i],words[j]) and words[j] not in selected_words:
                best = min(best, dfs(j,cnt + 1,[*selected_words, words[j]]))  # 자식의 답을 받아 최소만 남김
        return best          # 갈 곳이 없거나 전부 실패면 sys.maxsize가 그대로 올라감
```

여기서 **중립값이 무한대**인 이유가 핵심입니다.

- `min`으로 최솟값을 다투는 판에서, **시작값이 무한대**여야 어떤 실제 값이 와도 그보다 작아 갱신됩니다(`+`의 시작값이 `0`인 것과 같은 이치).
- **실패한 가지 = 무한대를 그대로 반환**합니다. 갈 곳이 없거나 자식이 전부 실패하면 `best`가 `sys.maxsize`인 채 위로 올라갑니다.
- 그러면 부모의 `min(...)` 경쟁에서 **무한대는 자동으로 탈락**합니다. 성공한 형제 가지의 실제 값이 있으면 그게 이기고, 형제도 전부 실패면 무한대가 계속 올라가 최종적으로 "길 없음"으로 판정됩니다.

> **한 줄 정리:** 집계 연산에는 **자기 짝꿍 중립값**이 있습니다 — 더하기는 `0`, 최솟값은 `무한대`.
> 실패 가지가 **중립값을 반환**하게 만들면, 그 가지는 결과에 아무 영향 없이 조용히 사라집니다.

## 7. DFS vs BFS 선택 기준

둘 다 그래프를 훑지만, **무엇을 답으로 원하느냐**에 따라 갈립니다.

| 원하는 답 | 고를 도구 | 이유 |
|---|---|---|
| **모든 경우·조합·경로 자체**를 세거나 만들어야 함 | **DFS** | 한 길 끝까지 파고들어 모든 갈래를 남김없이 뻗기 좋음 |
| 연결됐는지 / 덩어리 개수·크기 | **DFS** (BFS도 가능) | 전부 훑기만 하면 되므로 재귀가 간결 |
| **최단 거리·최소 겹수** | **BFS** | 가까운 것부터 겹 단위로 퍼져, 처음 닿는 순간이 최단 |

한 문장으로: **"모든 경우/경로가 답"이면 DFS**, **"최단·최소 몇 걸음"이면 BFS**를 먼저 떠올립니다.
(참고: `단어_변환`은 최소 횟수를 DFS로 모든 경로를 다 세어 `min`으로 골랐습니다. 이런 최단 계열은 겹 단위로 퍼지는 BFS가 더 어울릴 때가 많은데, 그 도구는 [학습_BFS](../problems/programmers/lv2/006_게임_맵_최단거리/학습_BFS.md)에서 익힙니다.)

# 풀이노트 — 입국심사

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

시간 별로, 증가함에 따라서 심사관의 등록 시간을 계산 하면 되는 문제입니다. 다만 경우의 수가 많아서 선형 방식으로 할 시 시간이 부족하게 됩니다. 따라서 심사관 등록 시간중 최소 값을 기준으로 목표 인원수 만큼 곱하여 최대 시간을 구하고, left - 1, right - 최대시간 으로 두고 이분 탐색을 진행하여 빠르게 값을 찾습니다.

## 시행착오 / 막혔던 점

이분 탐색을 활용해서 문제를 처음 풀어봐서 이분탐색 구현 포멧을 잘 사용하지 못했음. 이분탐색 로직 자체가 어려운 편은 아니기에, 약간의 학습 필요요

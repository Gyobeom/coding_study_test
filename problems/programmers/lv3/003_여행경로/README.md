## 문제

주어진 항공권을 모두 이용하여 여행경로를 짜려고 합니다. 항상 **"ICN"(인천) 공항에서 출발**합니다.

항공권 정보가 담긴 2차원 배열 `tickets`가 매개변수로 주어질 때, 방문하는 공항 경로를 배열에 담아 return 하도록 solution 함수를 작성해 주세요.

- 주어진 항공권은 **모두 사용**해야 합니다.
- 만일 가능한 경로가 여러 개인 경우 **알파벳 순서가 앞서는 경로**를 return 합니다.
- 모든 공항은 알파벳 대문자 3글자로 이루어집니다.
- 주어진 항공권은 하나의 경로로 이어질 수 있습니다(항상 모든 티켓을 사용하는 경로가 존재한다고 가정합니다).

각 항공권은 `[출발지, 도착지]` 형태입니다.

## 제약 조건

- `tickets`의 길이는 1 이상 10,000 이하입니다. (이 학습용 케이스는 규모를 작게 둡니다.)
- 공항 이름은 항상 **알파벳 대문자 3글자**입니다.
- 주어진 공항 수는 3,000개 이하이며, 항공권은 모두 사용해야 합니다.
- **같은 출발지·도착지를 가진 티켓이 중복으로 여러 장 존재할 수 있습니다.** (그래서 "간선을 방문 처리"할 때 공항 이름이 아니라 티켓 인덱스 단위로 관리해야 합니다.)
- 항상 모든 티켓을 사용하는 여행경로가 존재합니다.

## 입출력 예시

| tickets | return |
|---------|--------|
| `[["ICN","JFK"],["HND","IAD"],["JFK","HND"]]` | `["ICN","JFK","HND","IAD"]` |
| `[["ICN","SFO"],["ICN","ATL"],["SFO","ATL"],["ATL","ICN"],["ATL","SFO"]]` | `["ICN","ATL","ICN","SFO","ATL","SFO"]` |

- 예시 2 해설: `["ICN","SFO","ATL","ICN","ATL","SFO"]` 도 모든 티켓을 사용하는 경로지만, `["ICN","ATL","ICN","SFO","ATL","SFO"]` 가 **알파벳 순서상 더 앞서므로** 이쪽을 return 합니다.

## 힌트

이번 문제는 지금까지 푼 섬 넓이 / 네트워크 DFS와 **결정적으로 다른 지점**이 하나 있습니다.

- 같은 티켓이 중복으로 있을 수 있습니다. 그렇다면 방문 처리를 **무엇 단위로** 해야 할까요? (섬=칸, 네트워크=컴퓨터였다면, 여기는?)
- 사전순으로 앞서는 길을 먼저 골랐는데 그 길이 **막다른 길**이면 어떻게 해야 할까요? 지금까지의 DFS는 한 번 방문하면 끝이었지만, 이 문제는 그걸로는 안 됩니다. 이 지점이 이 문제에서 새로 배우는 개념(**백트래킹**)입니다.

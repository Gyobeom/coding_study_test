## 문제

주어진 항공권을 모두 이용하여 여행경로를 짜려고 합니다. 항상 **"ICN"(인천) 공항에서 출발**합니다.

항공권 정보가 담긴 2차원 배열 `tickets`가 매개변수로 주어질 때, 방문하는 공항 경로를 배열에 담아 return 하도록 solution 함수를 작성해 주세요.

- 주어진 항공권은 **모두 사용**해야 합니다.
- 만일 가능한 경로가 여러 개인 경우 **알파벳 순서가 앞서는 경로**를 return 합니다.
- 모든 공항은 알파벳 대문자 3글자로 이루어집니다.
- 주어진 항공권은 하나의 경로로 이어질 수 있습니다(항상 모든 티켓을 사용하는 경로가 존재한다고 가정합니다).

각 항공권은 `[출발지, 도착지]` 형태입니다.

## 제약 조건

- `tickets`의 길이는 1 이상 10,000 이하입니다. (이 학습용 케이스는 규모를 작게 둡니다.)
- 공항 이름은 항상 **알파벳 대문자 3글자**입니다.
- 주어진 공항 수는 3,000개 이하이며, 항공권은 모두 사용해야 합니다.
- **같은 출발지·도착지를 가진 티켓이 중복으로 여러 장 존재할 수 있습니다.** (그래서 "간선을 방문 처리"할 때 공항 이름이 아니라 티켓 인덱스 단위로 관리해야 합니다.)
- 항상 모든 티켓을 사용하는 여행경로가 존재합니다.

## 입출력 예시

| tickets | return |
|---------|--------|
| `[["ICN","JFK"],["HND","IAD"],["JFK","HND"]]` | `["ICN","JFK","HND","IAD"]` |
| `[["ICN","SFO"],["ICN","ATL"],["SFO","ATL"],["ATL","ICN"],["ATL","SFO"]]` | `["ICN","ATL","ICN","SFO","ATL","SFO"]` |

- 예시 2 해설: `["ICN","SFO","ATL","ICN","ATL","SFO"]` 도 모든 티켓을 사용하는 경로지만, `["ICN","ATL","ICN","SFO","ATL","SFO"]` 가 **알파벳 순서상 더 앞서므로** 이쪽을 return 합니다.

## 힌트

이번 문제는 지금까지 푼 섬 넓이 / 네트워크 DFS와 **결정적으로 다른 지점**이 하나 있습니다. 방향만 잡아 드리니 코드는 직접 완성해 보세요.

- **방문 처리 대상이 노드가 아니라 간선(티켓)입니다.** 섬·네트워크에서는 "이 칸/노드를 봤다"를 표시했지만, 여기서는 **"이 티켓 한 장을 썼다"**를 표시합니다. 같은 `[ICN, BBB]` 티켓이 2장 있을 수 있으므로, 공항 이름으로 방문 표시하면 안 됩니다. `used` 배열의 크기는 **티켓 개수(len(tickets))** 만큼 두고, 티켓 인덱스로 관리하세요.
- **사전순으로 먼저 시도하려면** `tickets`를 미리 정렬해 두고(또는 정렬된 순서로 순회하고), 매 갈림길에서 **앞에 있는(사전순 빠른) 티켓부터** 써 보세요. 가장 먼저 완성되는 경로가 곧 사전순 최소 경로가 됩니다.
- **이번 문제의 새 개념 — 백트래킹.** 사전순으로 먼저 고른 티켓이 **막다른 길**로 이어질 수 있습니다(그 공항에서 남은 티켓으로 더 못 나감). 이때는 **방금 쓴 표시를 되돌리고(`used[i] = False`) 경로에서도 빼서(`path.pop()`)** 다음 후보 티켓을 시도해야 합니다. 지금까지의 섬·네트워크 DFS는 한 번 방문하면 되돌릴 필요가 **없었다**는 점이 핵심 차이입니다.
- **완성 판정:** 모든 티켓을 다 썼다면 경로의 길이는 `len(tickets) + 1` 이 됩니다(티켓 N장을 쓰면 공항 N+1개를 방문). 이 길이에 도달하면 그때의 경로가 정답입니다.
- 문제에서 "항상 답이 존재한다"고 보장하므로, 사전순으로 성실히 백트래킹하면 **처음으로 완성에 도달한 경로**를 그대로 반환하면 됩니다.

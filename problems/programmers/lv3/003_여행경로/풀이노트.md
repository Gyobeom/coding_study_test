# 풀이노트 — 여행경로

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

경로를 끝까지 확인해서 해야하기에, DFS를 활용 하도록 하였음.

## 시행착오 / 막혔던 점

dfs에 반환 되는 부분에 대해서 조건에 부합하지 않을 경우 처리 하는 부분을 제대로 하지 못해서 특정 케이스에 대해서 성공하지 못했음. 그리고, 백트래킹 관련해서는 실패 지점의 대한 값을 원복시키고 다음 값으로 진행해야 하는 부분을 정상적으로 구현하지 못했음.

## 복잡도

- 시간복잡도: O(N^2)
- 공간복잡도: O(?)

dfs에서 반환 하는 부분에 대해서 조건을 달아서 해당 조건에 따른 처리 분기 로직을 진행해야 함을 배웠음.

# 단어 변환

> 관련 파일: [내 풀이 코드](solution.py) · [풀이노트(회고)](풀이노트.md)

- **출처**: 프로그래머스 lv3 "단어 변환"
- **난이도**: ★★★ (lv3)
- **분류**: 그래프 / DFS·BFS (암시적 그래프 — 간선이 배열로 주어지지 않고 규칙으로 정의됨)
- **링크**: https://school.programmers.co.kr/learn/courses/30/lessons/43163

## 문제

두 개의 단어 `begin`, `target`과 단어의 집합 `words`가 있습니다.
아래 규칙을 이용하여 `begin`에서 `target`으로 변환하는 **가장 짧은 변환 과정**을 찾으려고 합니다.

1. 한 번에 **한 개의 알파벳만** 바꿀 수 있습니다.
2. `words`에 있는 단어로만 변환할 수 있습니다.

예를 들어 `begin`이 `"hit"`, `target`이 `"cog"`, `words`가 `["hot","dot","dog","lot","log","cog"]`라면
`"hit" → "hot" → "dot" → "dog" → "cog"`와 같이 4단계를 거쳐 변환할 수 있습니다.

`begin`, `target`, `words`가 주어질 때, `begin`에서 `target`으로 변환하는 데 필요한
**가장 짧은 변환 단계 수**를 반환하세요. 변환할 수 없는 경우에는 `0`을 반환합니다.

## 제약 조건

- 각 단어의 길이는 3 이상 10 이하이며, **모든 단어의 길이는 같습니다**.
- `words`에는 3개 이상 50개 이하의 단어가 있습니다.
- `begin`과 `target`은 같지 않습니다.
- 변환할 수 없는 경우에는 `0`을 반환합니다.
- 모든 단어에는 중복이 없으며, 소문자 알파벳으로만 이루어져 있습니다.
- `target`이 `words`에 없더라도 변환이 불가능한 것으로 봅니다(도달할 수 없으므로 `0`).

## 입출력 예시

| begin | target | words | 반환값 | 설명 |
|-------|--------|-------|--------|------|
| `"hit"` | `"cog"` | `["hot","dot","dog","lot","log","cog"]` | `4` | `hit→hot→dot→dog→cog` |
| `"hit"` | `"cog"` | `["hot","dot","dog","lot","log"]` | `0` | `cog`가 words에 없어 도달 불가 |

## 힌트 (네트워크 → 단어 변환)

`네트워크` 문제와 **똑같은 그래프 DFS**입니다. 달라진 건 "간선이 어디에 있느냐"뿐입니다.

| | 네트워크 (인접 행렬) | 단어 변환 (암시적 그래프) |
|---|---|---|
| 정점 | 컴퓨터 번호 `i` | 단어 (begin + words의 각 단어) |
| 이웃(간선) | `computers[i][j] == 1` | **두 단어가 딱 한 글자만 다른가?** |
| 방문 표시 | `visited[i]` | `visited[단어의 words 인덱스]` |
| 답 | 시작한 횟수 | begin→target **최소 단계 수** |

- **간선이 배열로 주어지지 않습니다.** 대신 "두 단어가 한 글자만 다른가?"를 검사하는 함수가 곧 간선입니다.
  - `def diff_one(a, b): return sum(x != y for x, y in zip(a, b)) == 1`
  - 이 함수가 `True`면 `a`와 `b` 사이에 간선이 있는 셈입니다.
- **visited는 words의 인덱스 기준**으로 둡니다(`begin`은 항상 시작점이라 방문 배열이 필요 없습니다).
- 네트워크는 "개수"를 셌지만, 여기는 **최소**를 구해야 합니다.
  현재 단어에서 아직 방문 안 한 단어 중 한 글자만 다른 것으로 이동하며 단계를 하나씩 늘리고,
  `target`에 도달할 때마다 **min으로 최소 단계 수를 갱신**합니다.
- `words`가 최대 50개라 모든 경로를 훑는 DFS로도 충분합니다(최단이 목표라면 BFS는 첫 도달이 곧 최단이라 더 자연스럽지만, 둘 다 됩니다).

> ⚠️ `target`이 `words`에 아예 없으면 절대 도달할 수 없으니 `0`입니다. min 갱신이 한 번도 일어나지 않는 경우를 `0`으로 처리하세요.

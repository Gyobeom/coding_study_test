# 풀이노트 — 이중우선순위큐

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

배열에서 계속 해서 최솟값, 최댓값을 추출해야하고 신규 값을 넣어야해서, heapq을 사용하였음

## 시행착오 / 막혔던 점

입력되는 수가 -, + 이기에 해당 값들을 표준화할 필요가 있었음. 그래서 애초에 입력값에 최솟값이 2000000000 만큼 더해서 모든 값들을 정수로 만들었음. 이 과정을 하다가 생각하게 됨.

## 복잡도

- 시간복잡도: O(NlogN)
- 공간복잡도: O(?)

## 개선점 / 다른 풀이

중복되는 부분이 많아서 함수로 빼서 코드 작업 필요.

## 배운 점 (한 줄 요약)

최솟값|최댓값을 계속 구하거나 신규 값을 넣을 경우에는 heapq을 사용하여 빠르게 풀이가 가능하다. 일반 배열을 heapq을 활용해서 바로 만들고, heapq.heappush/heappop을 사용하여 값을 넣거나 뺄 수 있다. heapq을 사용한다고 해서 배열 자체가 정렬 되는 것은 아니다.

2개의 배열을 사용할 경우, 제외해야 하는 수가 있을 때 2개의 배열을 조절 해야하기에, 조절하는 로직을 구성해야함.

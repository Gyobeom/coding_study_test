## 문제

숫자가 삼각형 모양으로 놓여 있습니다. 삼각형은 **리스트의 리스트**로 주어지며, `i`번째 행에는 `i+1`개의 정수가 들어 있습니다(0-based).

```
    7
   3 8
  8 1 0
 2 7 4 4
4 5 2 6 5
```

맨 위 칸에서 시작해 **한 행씩 아래로** 내려갑니다. 어떤 칸에서 아래로 내려갈 때는 **바로 아래 칸** 또는 **바로 아래 오른쪽 칸**, 이 두 칸으로만 이동할 수 있습니다. 즉 `i`행 `j`열에서는 `i+1`행의 `j`열 또는 `j+1`열로만 갈 수 있습니다.

맨 위에서 맨 아래 행까지 내려오면서 거쳐 간 칸에 적힌 수들을 모두 더한 값을 **경로의 합**이라고 합니다. 위 삼각형에서 `7 → 3 → 8 → 7 → 5` 로 내려오면 합은 30이며, 이것이 가능한 경로 중 최댓값입니다.

삼각형 `triangle`이 주어질 때, 맨 위에서 맨 아래까지 내려오는 경로 합의 **최댓값**을 반환하세요.

## 제약 조건

- 삼각형의 높이(행의 수): 1 이상 500 이하.
- `triangle[i]`의 원소 개수는 `i + 1`개입니다(맨 윗행 1개, 그다음 2개, ...).
- 삼각형을 이루는 각 숫자: 0 이상 9,999 이하의 정수.

## 입출력 예시

| triangle | 반환값 |
|----------|--------|
| `[[7], [3, 8], [8, 1, 0], [2, 7, 4, 4], [4, 5, 2, 6, 5]]` | 30 |
| `[[3], [2, 4]]` | 7 |

- 첫 번째 예시: `7 → 3 → 8 → 7 → 5` 경로의 합 30이 최댓값입니다.
- 두 번째 예시: `3 → 4` 경로의 합 7이 최댓값입니다.

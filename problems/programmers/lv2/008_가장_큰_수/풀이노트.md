# 풀이노트 — 가장 큰 수

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

가장 큰수를 정렬 해서 풀어야 하는 문제.

## 시행착오 / 막혔던 점

기존 값을 기반으로 단순 정렬 하기에는 자릿수별로 다시 비교 해야 하는 경우가 발생하였음.
따라서, 해당 문제에서는 최대값이 1000까지라고 하니 자릿수는 최대 4자리이니 기존 값에서 * 3을 해서 문자열로 동일한 값을 복사,
이후 reverse 옵션을 둘 경우 문자열의 경우, 각 문자열 자리수 하나씩 비교하게 되는데, 이렇게 되면 각 숫자별로 자릿수 별로 비교하기에, 개별 자리 수 끼리 비교해서 정렬이 가능함.

## 복잡도

- 시간복잡도: O(N log N)
- 공간복잡도: O(?)

## 배운 점 (한 줄 요약)

자리수를 비교하면서 큰수를 만들어야 하는 경우, 정렬 옵션을 이용하고, key lambda를 이용해서 문자열로 변경 자리수 만큼 곱하는 방법을 배웠음 그리고 reverse 옵션 사용시 문자열 비교시 개별 자리수끼리 비교한다는 부분을 배웠음.

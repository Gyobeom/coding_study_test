# 학습: BFS (너비 우선 탐색)

> 관련 파일: [문제(README)](README.md) · [내 풀이 코드](solution.py) · [풀이노트(회고)](풀이노트.md)

지금까지는 그래프/격자를 전부 **DFS(재귀)** 로 훑었습니다. 이 문서에서 **BFS**라는 새 도구를 처음 익힙니다.
이 문서를 다 읽고 나면 `게임 맵 최단거리` 문제를 **스스로** 조립할 수 있어야 합니다.
그래서 이 문서에는 **게임 맵 최단거리의 풀이는 일부러 담지 않습니다.** 예제는 이미 통과한 `네트워크` 문제만 씁니다.

---

## 1. BFS란 무엇인가

DFS와 BFS는 "그래프를 전부 방문한다"는 목표는 같지만, **방문하는 순서**가 정반대입니다.

| | DFS (깊이 우선) | BFS (너비 우선) |
|---|---|---|
| 한 마디로 | **한 길로 끝까지** 파고들었다가 막히면 되돌아옴 | **가까운 것부터 한 겹씩** 넓게 퍼짐 |
| 비유 | 미로에서 한쪽 벽만 잡고 끝까지 걷기 | 연못에 돌을 던졌을 때 퍼지는 **물결(파문)** |
| 담아두는 도구 | **스택** (재귀 호출이 곧 스택) | **큐** (`deque`) |
| 되돌아옴 | 있음 (막히면 back) | 없음 (앞으로만 퍼짐) |

### 물결 비유

시작점에 돌을 하나 던지면, 파문은 **동심원**으로 퍼집니다.
- 먼저 거리 1인 이웃이 전부 젖고,
- 그 다음 거리 2, 그 다음 거리 3 …

BFS는 딱 이 순서로 노드를 방문합니다. "가까운 것을 **전부** 본 뒤에야" 다음 겹으로 넘어갑니다.
DFS는 반대로, 한 방향으로 멀리멀리 갔다가 막히면 돌아옵니다.

### 같은 그래프, 방문 순서 비교

이런 그래프가 있다고 합시다 (`0`이 시작, 아래로 갈수록 멀어짐):

```
        0
       / \
      1   2
     / \   \
    3   4   5
```

- **DFS** (한 길 끝까지): `0 → 1 → 3 → (막힘, back) → 4 → (back) → 2 → 5`
  방문 순서: **0, 1, 3, 4, 2, 5** — 3까지 깊이 내려갔다가 되돌아옵니다.
- **BFS** (겹 단위): `0` / 그 다음 겹 `1, 2` / 그 다음 겹 `3, 4, 5`
  방문 순서: **0, 1, 2, 3, 4, 5** — 거리 0 → 1 → 2 순서로 층층이.

DFS가 세로로 파고든다면, BFS는 **가로로 층을 채우며** 내려간다고 보면 됩니다.

## 2. 큐와 `collections.deque` 기초

BFS의 "한 겹씩 순서대로"를 만들어 주는 게 **큐(queue)** 입니다.

- **큐 = FIFO** (First In, First Out): **먼저 넣은 것이 먼저 나온다.** 매표소 줄서기와 같습니다.
  (참고: 스택은 LIFO, 나중에 넣은 게 먼저 나옴. 재귀 = 스택이라 DFS가 됨.)
- 먼저 넣은 것이 먼저 나오기 때문에, "거리 1인 것들"을 먼저 다 넣으면 "거리 1인 것들"이 먼저 다 나옵니다 → 겹 순서가 자동으로 지켜집니다.

파이썬에서는 `collections.deque`를 씁니다.

```python
from collections import deque

q = deque()      # 빈 큐
q.append(10)     # 뒤에 넣기      -> [10]
q.append(20)     #                -> [10, 20]
q.append(30)     #                -> [10, 20, 30]

x = q.popleft()  # 앞에서 꺼내기  -> x = 10, 큐는 [20, 30]
y = q.popleft()  #                -> y = 20, 큐는 [30]

print(x, y)      # 10 20  (넣은 순서대로 나옴 = FIFO)
print(len(q))    # 1
print(bool(q))   # True  (비어 있으면 False → while q: 로 "큐가 빌 때까지" 반복)
```

정리하면 BFS에서 쓰는 큐 조작은 딱 세 가지입니다.
- `q.append(x)` — 새로 발견한 노드를 **뒤에** 넣는다
- `q.popleft()` — **앞에서** 하나 꺼내 처리한다
- `while q:` — 큐가 빌 때까지 반복 (더 퍼질 곳이 없으면 끝)

> ⚠️ `list`로도 큐 흉내는 낼 수 있지만, `list.pop(0)`은 **앞 원소를 빼면 나머지를 전부 한 칸씩 당겨야 해서 O(n)** 입니다.
> `deque.popleft()`는 O(1)이라 훨씬 빠릅니다. BFS 큐는 항상 `deque`를 쓰세요.

## 3. 이미 푼 문제로 보는 BFS — `네트워크`

답안이 공개된 예제 문제 [네트워크](../../lv3/001_네트워크/README.md)(인접 행렬에서 연결 요소 개수 세기)를 BFS로 다시 풀어 봅니다.
**하는 일은 완전히 같습니다.** 재귀 대신 큐를 쓸 뿐입니다. (네트워크는 📎 예제 문제라 완성 코드를 봐도 되고, 같은 골격은 `가장_큰_네트워크`·`네트워크_크기_목록`에서 직접 통과시켰습니다.)

### DFS 원본 (예제로 공개된 답안 — 익숙한 그 골격)

```python
def solution(n, computers):
    visited = [False] * n

    def dfs(i):
        visited[i] = True
        for j in range(n):
            if computers[i][j] == 1 and not visited[j]:
                dfs(j)                       # 이웃을 만나면 곧장 그 안으로 파고듦

    cnt = 0
    for i in range(n):
        if not visited[i]:
            cnt += 1
            dfs(i)
    return cnt
```

### 같은 일을 하는 BFS (완성 코드 — 실행 검증 완료)

```python
from collections import deque

def solution(n, computers):
    visited = [False] * n

    def bfs(start):
        visited[start] = True                # ★ 큐에 넣기 직전에 방문 표시
        q = deque([start])                   # 시작 노드를 큐에 담고 출발
        while q:                             # 큐가 빌 때까지
            i = q.popleft()                  # 앞에서 하나 꺼내 "지금 처리 중"으로
            for j in range(n):
                if computers[i][j] == 1 and not visited[j]:
                    visited[j] = True        # ★ 넣는 순간 표시 (중복 방지)
                    q.append(j)              # 파고들지 않고 큐에 "예약"만
    cnt = 0
    for i in range(n):
        if not visited[i]:
            cnt += 1
            bfs(i)
    return cnt
```

### 줄 단위 대응

| DFS | BFS | 하는 일 |
|---|---|---|
| `visited[i] = True` (함수 첫 줄) | `visited[start] = True` + `q = deque([start])` | 시작점을 방문 처리하고 출발 |
| (재귀 스택이 자동으로 관리) | `while q:` | 아직 볼 게 남았는지 판단 |
| `dfs(i)` 진입 시점의 `i` | `i = q.popleft()` | 지금 처리할 노드를 꺼냄 |
| `for j in range(n): if ... and not visited[j]:` | (동일) | 이웃 후보 스캔 (인접 행렬이라 `range(n)`) |
| `dfs(j)` — **즉시** 그 노드 속으로 재귀 | `q.append(j)` — 큐에 **예약**만 하고 지금은 안 들어감 | 이웃을 다음에 볼 목록에 등록 |

**핵심 대응:** DFS의 `dfs(j)`(재귀 호출)가 BFS의 `q.append(j)`(큐에 넣기)로 바뀝니다.
DFS는 이웃을 만나는 즉시 그 안으로 **파고들지만**, BFS는 "나중에 볼 것"으로 **큐에 예약**만 하고 지금 겹을 마저 봅니다.
그래서 DFS는 세로로 내려가고, BFS는 층을 채우며 퍼집니다.

### ★ 방문 표시는 왜 "큐에 넣을 때" 하는가

BFS에서 방문 표시(`visited[j] = True`)는 **큐에 `append` 하는 그 순간**에 합니다. **꺼낼 때(`popleft` 직후)가 아닙니다.**

만약 "꺼낼 때 표시"로 하면 이런 일이 생깁니다.

```
노드 A의 이웃이 C, 노드 B의 이웃도 C 라고 하자.
A 처리 중 → C를 큐에 넣음  (아직 방문표시 안 함)
B 처리 중 → C가 아직 미표시라서 → C를 큐에 또 넣음   ← 중복!
```

C가 큐에 **두 번** 쌓입니다. 규모가 크면 같은 노드가 수십 번씩 중복되어 큐가 폭발하고 느려집니다.
그래서 **큐에 넣는 순간 바로 방문 표시**를 해서, 한 노드가 큐에 **딱 한 번만** 들어가도록 막습니다. 이건 격자든 인접 행렬이든 **BFS의 일반 원리**입니다.

## 4. 왜 "최단거리"에는 BFS인가

BFS는 시작점에서 **거리 1을 전부 → 거리 2를 전부 → 거리 3을 전부** 순서로 방문합니다(2절의 FIFO 덕분).
따라서 **어떤 칸에 처음 도달한 순간의 거리가 곧 그 칸까지의 최단거리**입니다. 나중에 더 먼 경로로 다시 와도, 이미 처음(=더 짧게) 도달했으므로 무시하면 됩니다.

작은 격자에 물결 번호(시작점에서의 거리)를 매겨 보면 한눈에 보입니다. `S`가 시작점입니다.

```
거리 표(BFS가 채워 넣는 순서):

   S 1 2 3
   1 2 3 4
   2 3 4 5
```

- `S`(거리 0)에서 한 겹 퍼지면 상·하·좌·우가 전부 **1**,
- 그 1들에서 다시 퍼지면 **2**, 그 다음이 **3** …
- 각 칸의 숫자는 "그 칸에 **처음** 닿았을 때의 거리" = 최단거리입니다.

### DFS로 최단을 구하면 왜 폭발하는가

DFS는 한 방향으로 끝까지 갔다가 되돌아오는 방식이라, "이 길로 간 게 최단인지"를 그 자리에서 알 수 없습니다.
결국 **가능한 모든 경로**를 다 걸어 본 뒤 그중 제일 짧은 것을 골라야 하는데, 격자에서 경로의 수는 칸 수에 대해 **지수적으로 폭발**합니다(같은 칸을 여러 경로가 다른 거리로 계속 재방문). 반면 BFS는 각 칸을 **처음 도달할 때 딱 한 번**만 확정하므로, 칸 수에 비례하는 시간이면 끝납니다. **"최단"이라는 단어를 보면 BFS를 떠올리세요.**

## 5. 격자로 옮길 때 달라지는 것 (개념만)

3절의 네트워크 BFS는 **인접 행렬**이었습니다. `게임 맵 최단거리`는 **격자**입니다. 뼈대(큐, `while q`, 넣을 때 방문표시)는 그대로지만, 두 가지가 달라집니다. **여기서부터는 코드로 보여주지 않습니다. 스스로 조립해 보는 것이 이 문제의 연습 포인트입니다.**

1. **이웃을 찾는 방법이 바뀐다.**
   - 네트워크(인접 행렬): 이웃 = `for j in range(n): if computers[i][j] == 1` 로 한 행을 스캔.
   - 격자: 이웃 = **상·하·좌·우 4방향** (`섬의 개수`에서 이미 써 본 4방향 관용구). 경계 밖·벽 검사도 그때처럼 필요합니다.

2. **"거리"를 어떻게 함께 들고 다닐지 스스로 설계해야 한다.**
   - 네트워크에서는 개수만 세면 됐지 거리는 필요 없었습니다.
   - 이번엔 각 칸까지의 **최단거리**를 답으로 내야 합니다. "지금 처리 중인 칸의 거리"를 큐와 함께 어떻게 전달하고, 새 칸에 도달했을 때 그 거리를 어떻게 정할지 — 이 설계가 이 문제의 핵심 연습입니다.

> ✋ 여기까지가 이 문서의 역할입니다. 위 두 가지(4방향 이웃 + 거리 들고 다니기)를 **직접** 조립해 보는 것이 `게임 맵 최단거리`의 연습 포인트입니다. 막히면 3절 네트워크 BFS 뼈대를 다시 보고, 무엇을 격자용으로 바꿔야 할지 스스로 대응시켜 보세요.

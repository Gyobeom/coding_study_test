# 풀이노트 — 타겟 넘버

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

모든 숫자를 사용하고, 각 수자를 +/- 를 이용해서 target 숫자로 만들어야 하기에, 완전탐색 DFS를 활용하였음

## 시행착오 / 막혔던 점

모든 숫자를 돌면서하기 for문을 생각하고 계속 dfs 함수 내에 반복을 작성하려고 하였으나, dfs 재귀 함수 구조를 활용해야 했음.

## 복잡도

- 시간복잡도: O(n^2)
- 공간복잡도: O(?)

## 개선점 / 다른 풀이

애초에 dfs에 종료 조건에 개수만 체크하고 이후 확인 조건으로 target 값과 동일하다면 1 아니면 0으로 했을 때, dfs 반환 값을 더하면 결국에는 1인 값들이 더해지니깐 개수 반환이 가능.

## 배운 점 (한 줄 요약)

dfs로 풀 때는 꼭 조건등을 명확하게 확인하고 진행하자. 그리고 반환 값을 1/0 으로 해서 총 개수에 대해서 더 간단하게 구현이 가능함.

## 문제

음이 아닌 정수 배열 `numbers`가 있습니다. 각 숫자 **앞에 `+` 또는 `-` 부호**를 하나씩 붙여
전부 더했을 때, 그 합이 타겟 넘버 `target`이 되는 **서로 다른 방법의 수**를 반환하세요.

- 배열의 **모든 숫자를 반드시 한 번씩** 사용합니다(고르는 게 아니라 부호만 정함).
- 같은 값이 배열에 여러 번 나와도 **위치가 다르면 다른 숫자**로 셉니다.

### 예시로 이해하기

`numbers = [1, 1, 1, 1, 1]`, `target = 3` 인 경우, 다음 5가지가 합 3을 만듭니다.

```
+1 +1 +1 +1 -1 = 3
+1 +1 +1 -1 +1 = 3
+1 +1 -1 +1 +1 = 3
+1 -1 +1 +1 +1 = 3
-1 +1 +1 +1 +1 = 3
```

→ **5가지**

## 제약 조건

- `1 <= numbers의 길이 <= 20`
- 각 원소는 `0 <= numbers[i] <= 50`  (0이 포함될 수 있습니다)
- `0 <= target <= 1000`

> 길이가 최대 20이므로 모든 부호 조합은 최대 `2^20 ≈ 100만` 가지 → 완전탐색으로 충분합니다.

## 입출력 예시

| numbers | target | 반환값 | 설명 |
|---------|--------|--------|------|
| `[1, 1, 1, 1, 1]` | `3` | `5` | 위 5가지 |
| `[4, 1, 2, 1]` | `4` | `2` | `+4+1-2+1`, `+4-1+2-1` |
| `[0, 0, 0]` | `0` | `8` | `±0`이 8조합, 모두 합 0 |

## 힌트 (부분수열의 합에서 한 걸음 더)

- 앞 문제(부분 수열의 합)가 **"이 원소를 넣는다 / 뺀다"** 2갈래였다면,
  이 문제는 **"이 원소에 `+`를 붙인다 / `-`를 붙인다"** 2갈래입니다. 구조가 똑같습니다.
- `dfs(i, cur)` = "i번째 원소부터 부호를 정할 차례이고, 지금까지 누적합이 `cur`" 라고 정의해 보세요.
  - **종료 조건**: `i == n`(모든 부호 결정 완료) → `cur == target`이면 1가지 성공, 아니면 실패.
  - 그 외: `dfs(i + 1, cur + numbers[i])` (`+` 붙임) 와 `dfs(i + 1, cur - numbers[i])` (`-` 붙임) 두 갈래.
- 성공 개수를 어떻게 셀지는 두 가지 스타일 모두 가능합니다.
  - **누적형**: 바깥의 `answer`를 `nonlocal`로 두고 성공할 때 `+= 1`.
  - **return형**: `dfs`가 성공 개수를 직접 반환하고 두 갈래를 더해 돌려줌 → `return dfs(...) + dfs(...)`.

> ⚠️ 두 갈래 모두 **`i + 1`** 로 인덱스를 반드시 진행해야 합니다(안 그러면 무한재귀 `depth exceeded`).

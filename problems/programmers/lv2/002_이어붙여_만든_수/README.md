# 이어 붙여 만든 수

- **난이도**: ★★☆ (lv2)

- **링크**: -

## 문제

한 자리 숫자들이 담긴 배열 `digits`가 주어집니다.

이 중에서 **원소를 하나 이상 골라, 원하는 순서로 이어 붙여** 정수를 만들 수 있습니다.
이렇게 만들 수 있는 **서로 다른 정수의 개수**를 반환하세요.

- 각 원소는 한 번 만든 수 안에서 **최대 한 번**만 쓸 수 있습니다(같은 위치의 숫자를 재사용 불가).
- **순서가 다르면 다른 수**입니다. 예: `1`과 `2`를 골라 `12`도, `21`도 만들 수 있습니다.
- 단, 만들어진 **정수 값이 같으면 한 가지로 셉니다.** (예: `[1, 1]`에서 두 `1`을 이어 붙이면 어느 순서든 `11`)

### 예시로 이해하기

`digits = [1, 2]` 인 경우 만들 수 있는 수:
- 한 개 사용: `1`, `2`
- 두 개 사용: `12`, `21`

→ 서로 다른 수 `{1, 2, 12, 21}` = **4개**

## 제약 조건

- `1 <= len(digits) <= 8`
- `1 <= digits[i] <= 9` (0은 주어지지 않습니다 → 앞자리 0 걱정 없음)
- 만들 수 있는 나열의 총 개수는 최대 `P(8,1)+…+P(8,8)` 약 10만 개 → **완전탐색으로 충분합니다.**

## 입출력 예시

| digits | 반환값 | 설명 |
|--------|--------|------|
| `[1, 2]` | `4` | `{1, 2, 12, 21}` |
| `[1, 1]` | `2` | `{1, 11}` — 두 `1`을 이어 붙이면 순서 무관 `11` |
| `[7]` | `1` | `{7}` |
| `[1, 2, 3]` | `15` | 한 개 3 + 두 개 6 + 세 개 6 |

## 힌트

- 이번엔 **순서가 중요**하고 각 원소를 **한 번씩만** 써야 합니다. → 어떤 원소를 이미 썼는지 기록하는 **방문 배열(`used`)** 이 필요합니다.
- DFS 구조: "현재까지 만든 문자열"을 들고 다니며, **아직 안 쓴 원소 각각**을 이어 붙여 재귀 → 돌아올 때 방문 표시를 되돌린다(**백트래킹**).
- 만든 수를 **집합(set)** 에 넣으면 같은 값이 자동으로 하나로 합쳐집니다. 마지막에 집합 크기를 반환.

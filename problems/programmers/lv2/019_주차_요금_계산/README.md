## 문제

어느 주차장의 입·출차 기록으로 각 차량의 주차 요금을 계산하려 합니다.

요금 정책 `fees` 와 입출차 기록 `records` 가 주어집니다.

- `fees = [기본 시간(분), 기본 요금(원), 단위 시간(분), 단위 요금(원)]` 입니다.
- `records` 의 각 원소는 `"HH:MM 차량번호 IN/OUT"` 형식의 문자열로, 하나의 입차 또는 출차 기록입니다.
  - `HH:MM` 은 24시간제 시각, `차량번호` 는 4자리 문자열, 세 번째 값은 입차면 `IN`, 출차면 `OUT` 입니다.
  - `records` 는 시각이 빠른 순서(시간 오름차순)로 정렬되어 있습니다.

**누적 주차 시간 계산**

1. 같은 차량은 여러 번 입·출차할 수 있으며, 한 차량의 누적 주차 시간은 **(출차 시각 − 입차 시각)** 을 모두 더한 값(분)입니다.
2. 어떤 차량이 입차 기록만 있고 그에 대응하는 출차 기록이 없다면, 그 차량은 **23:59 에 출차한 것으로 간주**하여 계산합니다.

**요금 계산 (차량 한 대 기준, 누적 주차 시간 `t` 분)**

- `t ≤ 기본 시간` 이면 요금은 **기본 요금**만 부과합니다.
- `t > 기본 시간` 이면 요금은 `기본 요금 + ceil((t − 기본 시간) / 단위 시간) × 단위 요금` 입니다.
  - `ceil` 은 올림입니다. 초과 시간이 단위 시간의 배수가 아니면 올려서 한 단위를 더 부과합니다.

**반환**

- 차량번호를 **오름차순**으로 정렬했을 때, 각 차량의 요금(원)을 그 순서대로 담은 배열을 반환합니다.

## 제약 조건

- `fees` 의 길이는 4이며 `[기본 시간, 기본 요금, 단위 시간, 단위 요금]` 입니다.
  - 기본 시간: 1 이상 1,439 이하(분). 기본 요금: 0 이상 100,000 이하(원).
  - 단위 시간: 1 이상 1,439 이하(분). 단위 요금: 1 이상 100,000 이하(원).
- `records` 배열의 길이는 1 이상 1,000 이하입니다.
- 각 기록은 `"HH:MM 차량번호 IN/OUT"` 형식이며, 공백 하나로 구분됩니다.
  - 시각 `HH:MM` 은 `00:00` 이상 `23:59` 이하이고, `records` 는 시간 오름차순으로 주어집니다.
  - `차량번호` 는 `"0000"` 이상 `"9999"` 이하의 4자리 문자열입니다.
  - 같은 차량이 연속으로 두 번 입차하거나, 입차 없이 출차하는 잘못된 기록은 주어지지 않습니다.

## 입출력 예시

| fees | records | 반환값 |
|------|---------|--------|
| `[180, 5000, 10, 600]` | `["05:34 5961 IN","06:00 0000 IN","06:34 0000 OUT","07:59 5961 OUT","07:59 0148 IN","18:59 0000 IN","19:09 0148 OUT","22:59 5961 IN","23:00 5961 OUT"]` | `[14600, 34400, 5000]` |
| `[120, 0, 60, 591]` | `["16:00 3961 IN","16:00 0202 IN","18:00 3961 OUT","18:00 0202 OUT","23:58 3961 IN"]` | `[0, 591]` |

첫 번째 예시 설명(차량번호 오름차순 `0000, 0148, 5961`):
- `0000`: `06:34−06:00`(34분) + `23:59−18:59`(300분, OUT 없어 23:59 간주) = 334분. `334 > 180` 이므로 `5000 + ceil((334−180)/10)×600 = 5000 + 16×600 = 14600`.
- `0148`: `19:09−07:59` = 670분. `5000 + ceil((670−180)/10)×600 = 5000 + 49×600 = 34400`.
- `5961`: `07:59−05:34`(145분) + `23:00−22:59`(1분) = 146분. `146 ≤ 180` 이므로 기본 요금 `5000`.

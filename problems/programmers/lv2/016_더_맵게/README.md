## 문제

음식의 스코빌 지수(매운 정도)가 담긴 배열 `scoville`이 있습니다. 모든 음식의 스코빌 지수를 특정 값 `K` 이상으로 만들고 싶습니다.

스코빌 지수가 `K` 미만인 음식이 남아 있는 동안, 다음 규칙으로 두 음식을 섞어 새로운 음식을 만듭니다.

> 새 음식의 스코빌 지수 = (가장 안 매운 음식의 스코빌 지수) + (두 번째로 안 매운 음식의 스코빌 지수) × 2

섞은 두 음식은 사라지고, 새로 만든 음식 한 개가 대신 들어갑니다. 이 과정을 모든 음식의 스코빌 지수가 `K` 이상이 될 때까지 반복합니다.

배열 `scoville`과 정수 `K`가 주어질 때, 모든 음식의 스코빌 지수를 `K` 이상으로 만들기 위해 섞어야 하는 **최소 횟수**를 반환하세요. 아무리 섞어도 모든 음식을 `K` 이상으로 만들 수 없는 경우에는 `-1`을 반환합니다.

## 제약 조건

- `scoville`의 길이: 2 이상 1,000,000 이하.
- `scoville`의 원소(각 음식의 스코빌 지수): 0 이상 1,000,000 이하의 정수.
- `K`: 0 이상 1,000,000,000 이하의 정수.
- 처음부터 모든 원소가 `K` 이상이면 섞을 필요가 없으므로 반환값은 `0`입니다.
- 음식이 1개만 남았는데도 그 값이 `K` 미만이면 더 섞을 수 없으므로 `-1`을 반환합니다.

## 입출력 예시

| scoville | K | 반환값 |
|----------|---|--------|
| `[1, 2, 3, 9, 10, 12]` | 7 | 2 |
| `[1, 1]` | 7 | -1 |
| `[10, 20, 30]` | 5 | 0 |

첫 번째 예시: `1 + 2*2 = 5`를 섞어 `[3, 5, 9, 10, 12]`, 다시 `3 + 5*2 = 13`을 섞어 `[9, 10, 12, 13]`이 되어 모두 7 이상이므로 2회.

## 문제

효진이는 결승선까지 총 `n`칸을 뛰어서 가려고 합니다. 한 번에 **1칸** 또는 **2칸**씩 뛸 수 있습니다.

예를 들어 4칸을 뛰어야 한다면 다음과 같은 방법들이 있습니다.

- 1칸, 1칸, 1칸, 1칸
- 1칸, 2칸, 1칸
- 2칸, 1칸, 1칸
- 1칸, 1칸, 2칸
- 2칸, 2칸

즉 4칸을 가는 방법은 총 5가지입니다.

효진이가 결승선인 `n`칸을 뛰어서 도달하는 **방법의 수**를 반환하세요. 방법의 수가 매우 커질 수 있으므로, **결과를 1234567로 나눈 나머지**를 반환합니다.

## 제약 조건

- `n`: 1 이상 2,000 이하의 자연수.
- `n = 1`이면 방법은 1가지, `n = 2`이면 방법은 2가지입니다.
- 반환값은 `(방법의 수) % 1234567` 입니다.

## 입출력 예시

| n | 반환값 |
|---|--------|
| 4 | 5 |
| 3 | 3 |

- `n = 4`: 위 설명대로 5가지.
- `n = 3`: (1,1,1), (1,2), (2,1) 로 3가지.

## 문제

피보나치 수는 다음과 같이 정의됩니다.

- `F(0) = 0`
- `F(1) = 1`
- `F(n) = F(n-1) + F(n-2)` (단, `n >= 2`)

즉 앞의 두 항을 더해 다음 항을 만듭니다. 처음 몇 항은 `0, 1, 1, 2, 3, 5, 8, 13, ...` 입니다.

자연수 `n`이 주어질 때 `n`번째 피보나치 수 `F(n)`을 반환하세요. 값이 매우 커질 수 있으므로, **결과를 1234567로 나눈 나머지**를 반환합니다.

## 제약 조건

- `n`: 2 이상 100,000 이하의 자연수.
- `n`이 매우 클 수 있으므로, 정의를 그대로 재귀 호출하는 완전탐색으로는 시간 안에 계산할 수 없습니다.
- 반환값은 `F(n) % 1234567` 입니다.

## 입출력 예시

| n | 반환값 |
|---|--------|
| 3 | 2 |
| 5 | 5 |

- `n = 3`: `F(3) = 2`.
- `n = 5`: `F(5) = 5`.

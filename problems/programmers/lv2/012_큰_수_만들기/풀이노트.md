# 풀이노트 — 큰 수 만들기

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

문자열 배열에서 특정 값을 제거하여, 만들 수 있는 가장 큰 수를 구해야 하는데, 이때 전체 숫자 배열의 경우 최대 1,000,000 이기 떄문에 경우의 수가 너무 커져, DFS를 할 수 없음. 따라서 그리드 방식으로 진행 해야함.

## 시행착오 / 막혔던 점

문자열 자리를 그대로 지키면서 비교 해야하는 부분이 있는데, 이를 하려고 별도의 배열을 만들어서 처리하려고 했고, 최대 값을 찾아서 처리 하려고 했는데, 이렇게 할 경우 문제 풀이를 할 수가 없음.

## 복잡도

- 시간복잡도: O(?)
- 공간복잡도: O(?)

## 개선점 / 다른 풀이

문자열을 돌면서, 직전 값들을 비교 하는 방법을 사용. 이때 stack을 활용해서 값을 넣고, stack에 값이 들어있고, stack값과 비교 했을 때, stack 값이 더 작고, 뺴야 하는 개수가 미만이라면, 스택에서 값을 뻄, 그리고 정상적으로 남는 값들도 stack에 넣어서 최종적으로는 stack에 뺸 나머지 값들만 남게 되고, 마지막으로 join 사용해서 반환 .

이때 끝까지 돌았음에도 뺀 수 카운트가 부족하다면, 이는 오름 내림차순으로 되어 있어서 뺼 수 없었던 구조, 따라서 slice를 활용해서 뒤에서부터 카운트 수 만큼 잘라서 반환

## 배운 점 (한 줄 요약)

그리드를 사용할 때, 조건식을 잘 만들어야 하고, 그에 따른 로직을 잘 만들어야함.

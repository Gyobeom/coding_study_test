## 문제

숫자로만 이루어진 문자열 `number`가 주어집니다. 이 수에서 **`k`개의 숫자를 제거**하여 만들 수 있는 수 중 **가장 큰 수**를 구하려고 합니다.

- 제거는 자리 하나(문자 하나) 단위로 이루어지며, 정확히 `k`개를 제거합니다.
- **남은 숫자들의 순서는 원래 순서를 그대로 유지**해야 합니다(자리를 섞을 수 없습니다).

예를 들어 `number = "1924"`, `k = 2`라면 "19", "12", "14", "92", "94", "24" 중 가장 큰 수는 **"94"** 입니다.
`number = "1231234"`, `k = 3`이면 가장 큰 수는 **"3234"** 입니다.

가장 큰 수를 **문자열로** 반환하세요.

## 제약 조건

- `number`의 길이: 1 이상 1,000,000 이하. 각 문자는 `'0'`~`'9'`입니다.
- `k`: 1 이상 (`number`의 길이) 이하의 정수. 즉 **`k`가 `number`의 자릿수와 같을 수도** 있습니다(이 경우 모두 제거되어 결과가 빈 문자열이 될 수 있습니다).
- 입력 길이가 최대 100만이므로, 모든 조합을 만들어 비교하는 방식으로는 시간 내에 풀 수 없습니다.
- 남은 숫자의 순서는 유지되며, 어느 자리를 지울지는 자유입니다(예: `"10"`에서 1개를 제거하면 `"1"`과 `"0"` 중 더 큰 `"1"`).

## 입출력 예시

| number | k | 반환값 |

| `"1231234"` | 3 | `"3234"` |
| `"4177252841"` | 4 | `"775841"` |
| `"10"` | 1 | `"1"` |

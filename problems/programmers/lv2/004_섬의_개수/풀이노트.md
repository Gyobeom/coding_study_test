# 풀이노트 — 섬의 개수

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

좌표 값에서 상,하,좌,우를 돌면서 섬들이 연결되어 잇는 개수를 구해야 하기에 DFS를 활용 하였음.

## 시행착오 / 막혔던 점

dfs 함수 내부에서 카운트를 해결하려고 했으나, 그렇게 될 경우, 재귀 함수를 호출 할 때마다, cnt를 증가 시켜 잘못된 개수를 반환 함.

## 복잡도

- 시간복잡도: O(R>C)
- 공간복잡도: O(?)

## 개선점 / 다른 풀이

DFS는 연결된 상,하,좌,우를 방문하는 방문자 역할이고, 외부에 이중 반복문을 통해서 최초 1인 지역을 방문 하고, 카운트를 증가시키고, 관련 주변에 연결된 섬들을 처리할 수 있도록 DFS를 호출 해 처리 하도록 함.

## 배운 점 (한 줄 요약)

DFS를 이용한 좌표 방문 문제에서, 좌표 값 내부에서 순회 할 수 있도록 검사하는 별도의 함수가 필요. dfs에서는 4방향의 좌표를 순회 하면서 방문 처리 진행하고, 이때, 좌표 값 내부 그리고 방문 가능한 곳만 갈 수 있도록 확인하는 함수를 호출 하여 통관 된 좌표만 방문 진행.

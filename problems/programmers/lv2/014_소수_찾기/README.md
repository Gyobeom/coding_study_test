## 문제

각 종이 조각에 **한 자리 숫자**가 하나씩 적힌 종이 조각들이 있습니다. 예를 들어 `"17"`이라면 `1`이 적힌 조각과 `7`이 적힌 조각 두 개입니다.

이 조각들 중 **일부 또는 전부를 붙여** 만들 수 있는 수 가운데, **소수**가 몇 개인지 구하려고 합니다.

- 조각을 원하는 순서로 이어 붙일 수 있으며, 사용하는 조각의 개수도 1개부터 전체까지 자유입니다.
- 서로 다른 방식으로 붙였더라도 **같은 수가 되면 하나로만 셉니다**(중복 제거). 예를 들어 조각 `0,1,1`로 `"011"`을 만들면 이는 수 `11`이며, 다른 조합으로 만든 `11`과 **같은 수**로 봅니다.
- 앞에 `0`이 붙은 경우는 그 `0`을 무시한 값으로 봅니다(`"011"` → `11`, `"07"` → `7`).
- `0`과 `1`은 **소수가 아닙니다.** 소수는 1과 자기 자신으로만 나누어지는 2 이상의 자연수입니다.

숫자 조각이 이어진 문자열 `numbers`가 주어질 때, 만들 수 있는 서로 다른 수 중 **소수의 개수**를 반환하세요.

예를 들어 `numbers = "17"`이면 만들 수 있는 수는 `1, 7, 17, 71` 등이며, 이 중 소수는 `7, 17, 71`로 **3개**입니다.

## 제약 조건

- `numbers`의 길이: 1 이상 7 이하.
- `numbers`의 각 문자는 `'0'`~`'9'`이며, **같은 숫자가 여러 번** 나올 수 있습니다(예: `"011"`).
- 만들 수 있는 수는 서로 다른 값 기준으로 셉니다(중복 제거).
- 앞자리 `0`은 무시한 값으로 취급합니다.
- `0`과 `1`은 소수가 아닙니다.

## 입출력 예시

| numbers | 반환값 |
|---------|--------|
| `"17"` | 3 |
| `"011"` | 2 |

- 예시 2: 조각은 `0, 1, 1`. 만들 수 있는 서로 다른 수는 `0, 1, 10, 11, 101, 110` 등이며, 이 중 소수는 `11, 101`로 **2개**입니다.

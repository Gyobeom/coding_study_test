# 풀이노트 — 부분 수열의 합

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

처음에는 for 중첩 반복문을 사용해서 진행하는 방식으로 하려고 했으나, 뽑는 개수가 가변이기 때문에 되지 않았음.
따라서 재귀 함수를 통해서 DFS 방식을 활용해서 숫자를 사용하거나 / 사용하지 않거나의 나눠서 진행하는 방식을 활용

## 시행착오 / 막혔던 점

특정 개수를 지정하여 반복하거나, 부분 집합의 경우 중첩 반복문을 통해서 해결 할 수 있으나, 부분집합의 가변일 경우에는 중첩 반복문으로 해결할 수 없음. 따라서, DFS 백트레킹 방식을 활용해서 진행했어야함.

## 복잡도

- 시간복잡도: O(N^2)
- 공간복잡도: O(?)

## 개선점 / 다른 풀이

완전 탐색에서의 DFS 활용 방법에 대해서 익숙하지 않아서, 풀지 못했음. 해당 부분에 대한 학습이 필요.

## 배운 점 (한 줄 요약)

특정 개수를 지정한 경우에는 for 중첩 반복문으로 해결이 가능하나, 뽑는 개수|깊이가 가변일 경우에는 재귀/ 백트래킹(DFS)를 활용해서 문제를 풀어보자

## 문제

정수 배열 `nums`와 정수 `target`이 주어집니다.

`nums`에서 **원소를 하나 이상 골라 만든 부분집합** 중에서, 고른 원소들의 **합이 `target`과 같은
경우의 수**를 반환하세요.

- 원소는 **인덱스로 구분**합니다. 즉 값이 같아도 위치가 다르면 서로 다른 원소로 셉니다.
- 부분집합에서 **원소의 순서는 상관없습니다**. (예: 인덱스 `{0, 2}`를 고른 경우와 `{2, 0}`은 같은 한 가지입니다.)
- 각 원소는 한 부분집합 안에서 **최대 한 번**만 쓸 수 있습니다.
- 아무것도 고르지 않는 **공집합은 세지 않습니다.**

## 제약 조건

- `1 <= len(nums) <= 20`
- `1 <= nums[i] <= 1,000`
- `1 <= target <= 20,000`
- 원소 개수가 최대 20개이므로 전체 부분집합은 최대 `2^20 ≈ 100만` 개입니다. → **완전탐색으로 충분합니다.**

## 입출력 예시

| nums | target | 반환값 | 설명 |
|------|--------|--------|------|
| `[1, 2, 3, 4, 5]` | `5` | `3` | `{5}`, `{1,4}`, `{2,3}` |
| `[3, 3, 3]` | `3` | `3` | 값은 같지만 인덱스가 다른 세 원소 각각 |
| `[1, 2, 3]` | `7` | `0` | 만들 수 있는 합이 없음 |
| `[1, 1, 1, 1]` | `2` | `6` | 네 개 중 두 개를 고르는 모든 경우 = C(4,2) |

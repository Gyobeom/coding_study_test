## 접근 방법

경우의 수를 구하는 문제에 타입별로 몇개인지를 알기 위해서 Counter 함수를 사용해야 했음.

## 시행착오 / 막혔던 점

곱셈의 법칙을 이용해서 풀었어야 했는데, 해당 부분에 대해서 활용하지 못했음.

## 복잡도

- 시간복잡도: O(N)
- 공간복잡도: O(?)

## 배운 점 (한 줄 요약)

Counter를 이용해서 분리 해서 숫자를 뽑아 내는 방법을 배웠음. 그리고, 경우의 수를 계산 할 때, 곱셈의 법칙을
이용해서 각 타입별 경우의 수 (옷 개수 + 안입는 경우) 까지 해서 모든 타입을 누적해서 곱하고 마지막으로 전체를
안입는 경우가 없으니 -1을 반환 하는 방식 추후 경우의 수 문제가 나올 경우 잘 참고해서 진행해야 겠음

# 풀이노트 — 신고 결과 받기

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

이용자 ID와 신고당한ID에서 중복 신고를 제외하고, 실제 신고수를 기반으로 K번 이상일 경우 메일 발송 횟수를 반환 함. 해당 문제는 set, Counter, defaultdict를 활용해서 풀기로 하였음.

## 시행착오 / 막혔던 점

먼저 set을 통해서 신고한 부분에서 중복 신고를 제외하고, 이후 해당 신고해서 신고자와, 신고 당한 피신고인을 분리 하여 사전으로 생성. 이후 해당 사전을 돌면서 k번 이상 신고 당했을 경우에는 신고자들을 배열에 넣었고, 마지막으로 유저 id를 순회하면서 신고자 배열에서 값을 확인해서 몇번 신고 메일을 받았는지 확인 후 반환 하였음.

## 복잡도

- 시간복잡도: O(N)
- 공간복잡도: O(?)

## 문제

게시판 불량 이용자를 신고하고 처리 결과를 메일로 알려주는 시스템을 개발하려 합니다.

각 유저는 다른 유저를 **신고**할 수 있고, 처리 규칙은 다음과 같습니다.

1. **신고 형식**: `"이용자ID 신고당한ID"` 형태의 문자열 하나로 신고 한 건을 나타냅니다.
   - 예: `"ryan con"` → `ryan`이 `con`을 신고했다는 뜻입니다.
2. **한 유저가 같은 유저를 여러 번 신고해도 1회로만 처리**됩니다.
   - 단, **서로 다른 유저를 각각 신고하는 것**은 각각 별개로 집계됩니다.
   - (예: `frodo`가 `neo`를 여러 번 신고해도 "frodo가 neo를 신고함" 1건입니다.)
3. **k번 이상 신고당한 유저는 게시판 이용이 정지**되며, 신고한 유저에게 정지 사실을 메일로 발송합니다.
   - 여기서 "k번 이상"은 **서로 다른 유저에게** 신고당한 횟수(중복 제거 후 집계)를 뜻합니다.
4. 유저가 받은 결과 메일 수 = **자신이 신고한 유저 중, 최종적으로 정지된 유저의 수**입니다.

`id_list`(이용자 ID 목록), `report`(신고 내역 문자열 목록), `k`(정지 기준 신고 횟수)가 주어질 때,
각 유저가 받은 결과 메일 수를 **`id_list`에 담긴 순서대로** 배열에 담아 반환하세요.

## 제약 조건

- `id_list`의 길이는 2 이상 1,000 이하입니다.
  - `id_list`의 원소(유저 ID)는 1 이상 10 이하의 알파벳 소문자로 이루어져 있으며, 서로 중복되지 않습니다.
- `report`의 길이는 1 이상 200,000 이하입니다.
  - 각 원소는 `"이용자ID 신고당한ID"` 형식이며, 두 ID는 공백 하나로 구분되고 서로 다릅니다.
  - 두 ID는 모두 `id_list`에 존재하는 ID입니다.
  - **같은 신고 내역(이용자ID·신고당한ID 쌍)이 여러 번 들어올 수 있으나, 이 경우 1회로만 처리**합니다.
- `k`는 1 이상 200 이하의 자연수입니다.

## 입출력 예시

| id_list | report | k | 반환값 |
|---------|--------|---|--------|
| `["muzi", "frodo", "apeach", "neo"]` | `["muzi frodo", "apeach frodo", "frodo neo", "muzi neo", "apeach muzi"]` | `2` | `[2, 1, 1, 0]` |
| `["con", "ryan"]` | `["ryan con", "ryan con", "ryan con", "ryan con"]` | `3` | `[0, 0]` |

첫 번째 예시 설명:
- `frodo`는 `muzi`, `apeach` 2명에게 신고당해 정지됨. `neo`는 `frodo`, `muzi` 2명에게 신고당해 정지됨.
- 정지된 유저: `frodo`, `neo`.
- `muzi`는 `frodo`·`neo`를 신고 → 둘 다 정지 → 메일 2통. `frodo`는 `neo`를 신고 → 메일 1통. `apeach`는 `frodo`·`muzi`를 신고했으나 정지된 건 `frodo`뿐 → 메일 1통. `neo`는 신고한 적 없음 → 0통.

두 번째 예시 설명:
- `ryan`이 `con`을 4번 신고했지만 중복 제거로 1회 처리 → `con`은 1번 신고당함. k=3 미만이라 정지되지 않음 → 아무도 메일을 받지 않음 → `[0, 0]`.

# 풀이노트 — 체육복

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

n의 값이 20 이상이기에 전체를 비교하면서 할 수 없었음. 전체를 다 비교하는게 아니라 우선 특정 조건을 만족하는 것들을 찾아서 제외 처리 하였고, 무조건 맞는 조건으로만 가도록 했기에 그리드 방식을 사용 함.

## 시행착오 / 막혔던 점

옷을 빌려주려 가져온 학생과 도난당한 학생들이 동일한 케이스를 생각하지 못했음. 앞서서 filter를 활용해서 lost 배열 값도 확인하여 해당 부분을 처리 하였음.

## 복잡도

- 시간복잡도: O(N)
- 공간복잡도: O(?)

## 배운 점 (한 줄 요약)

문제에 나와있는 각 조건을 잘 보고 각 조건들을 만들어서 해결해야함. set 을 이용해서 배열끼리 빼서 차집합을 만들 수 있다는 것을 알았음. discard를 사용해서 remove 처럼 배열에서 제거 할 수 있으나, 지우려는 값이 없어도 에러발생이 되지 않아 if x in s: 처럼 확인할 필요 없이 안전하게 삭제 가능.

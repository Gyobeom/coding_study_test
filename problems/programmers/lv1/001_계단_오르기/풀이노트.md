# 풀이노트 — 계단 오르기

> 관련 파일: [문제 설명](README.md) · [내 풀이 코드](solution.py)

내가 직접 채우는 회고 문서. 문제를 풀고 나서(또는 푸는 도중) 자유롭게 기록한다.
아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

해당 문제는 특정 목표를 향해서 +1 또는 +2를 진행해서 도달한 경우의 수를 구하는 문제이므로,
전체 완전 탐색을 진행하였음.

## 시행착오 / 막혔던 점

dfs에 익숙하지 않다보니 함수는 잘 만들어두고, 실제를 DFS를 호출 하는 부분을 빼먹었음.

## 복잡도

- 시간복잡도: O(N^2)
- 공간복잡도: O(?)

## 개선점 / 다른 풀이

answer 변수에 반환 하는 형태로 했는데, 그게 아닌 return 에서 더하는 값으로 조건 분기에서 반환 후 최종적으로는 재귀를 호출하는 함수들을 return dfs(cnt + 1) + dfs(cnt + 2) 이렇게 하는 형태로 반환하여 더 간단하게 작성 가능.

## 배운 점 (한 줄 요약)

DFS를 활용한 문제를 풀었고, 조건 분기를 잘 정해야 할 것으로 보임. DFS에서 어떤 조건으로 분기를 가져갈 것인지, 그리고 완료되는 부분에 대한 조건은 어떻게 처리 할 것인지 이러한 부분이 중요해보임

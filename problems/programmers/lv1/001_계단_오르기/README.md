## 문제

`n`칸짜리 계단이 있습니다. 한 번에 **1칸 또는 2칸**을 올라갈 수 있습니다.
맨 아래(0칸)에서 시작해 꼭대기(`n`칸)에 **정확히 도달**하는 서로 다른 방법의 수를 반환하세요.

- **밟는 순서가 다르면 다른 방법**입니다. 예: `1칸+2칸`과 `2칸+1칸`은 서로 다릅니다.

### 예시로 이해하기

`n = 3` 인 경우:
- `1 + 1 + 1`
- `1 + 2`
- `2 + 1`

→ **3가지**

## 제약 조건

- `1 <= n <= 25`

## 입출력 예시

| n | 반환값 | 설명 |
|---|--------|------|
| `1` | `1` | `1` |
| `2` | `2` | `1+1`, `2` |
| `3` | `3` | `1+1+1`, `1+2`, `2+1` |
| `4` | `5` | 위 3가지에 한 칸 더 얹는 조합들 |

## 힌트 (재귀의 기본기)

이 문제는 방문 배열도, 배열 인덱스도 필요 없습니다. **재귀 함수가 값을 직접 반환**하도록 만들면 깔끔합니다.

- "지금 위치 `pos`에서 꼭대기까지 가는 방법의 수"를 구하는 함수 `dfs(pos)`를 생각해 보세요.
- **종료 조건 2개**:
  - `pos == n` 이면 → 딱 도착 → **1가지**(성공)
  - `pos > n` 이면 → 지나쳐 버림 → **0가지**(실패)
- 그 외에는 **1칸 오른 경우 + 2칸 오른 경우**를 더합니다:
  `return dfs(pos + 1) + dfs(pos + 2)`

즉 "한 걸음의 선택(1칸/2칸)"이 갈림길이고, 각 갈림길의 결과를 **더해서** 돌려주면 됩니다.

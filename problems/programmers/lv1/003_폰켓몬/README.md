## 문제

당신은 폰켓몬 `N`마리를 가지고 있습니다. 이 폰켓몬들 중 **정확히 절반(N/2마리)** 만 골라 데려가려고 합니다.

각 폰켓몬은 종류를 나타내는 번호를 가지고 있으며, 같은 번호는 같은 종류의 폰켓몬임을 뜻합니다.
당신은 데려갈 N/2마리를 고를 때, **가능한 한 많은 종류의 폰켓몬**을 데려가고 싶습니다.

폰켓몬의 종류 번호가 담긴 배열 `nums`가 주어질 때(배열의 길이는 항상 짝수),
N/2마리를 골랐을 때 **가질 수 있는 종류 수의 최댓값**을 반환하세요.

예를 들어 `nums = [3, 1, 2, 3]`이면 N은 4이므로 2마리를 고를 수 있습니다.
종류는 {1, 2, 3}이 있으므로, 서로 다른 종류로 2마리(예: 1번과 2번)를 고르면 종류 수 2를 얻을 수 있어 최댓값은 2입니다.

## 제약 조건

- `nums`의 길이(N)는 1 이상 10,000 이하의 자연수이며, **항상 짝수**입니다.
- `nums`의 각 원소(폰켓몬 종류 번호)는 1 이상 200,000 이하의 자연수입니다.
- 고를 수 있는 폰켓몬의 수는 항상 N/2마리입니다.

## 입출력 예시

| nums | 반환값 | 설명 |
|------|--------|------|
| `[3, 1, 2, 3]` | `2` | 4마리 중 2마리 선택. 종류 {1,2,3} 중 서로 다른 2종류를 고를 수 있음 |
| `[3, 3, 3, 2, 2, 4]` | `3` | 6마리 중 3마리 선택. 종류 {2,3,4} 3종류를 모두 고를 수 있음 |
| `[3, 3, 3, 2, 2, 2]` | `2` | 6마리 중 3마리 선택. 종류는 {2,3} 2종류뿐이라 최대 2 |

## 접근 방법

중복 되는 값에서 N/2를 고를 때, 최대한 많이 고르는 개수를 반환 하는 문제.
따라서 배열 중복 제거를 위해 set 함수를 이용한 풀이 진행
set 함수를 통해서 중복 제거가 진행된 개수와, N/2 개수를 비교 하여, N/2 개수보다 많을 경우에는
N/2 개수가 최대 값이 되니 해당 값을 반환 하고, 아닐 경우에는 중복 값을 제거한 개수를 반환 하도록. 하였음.

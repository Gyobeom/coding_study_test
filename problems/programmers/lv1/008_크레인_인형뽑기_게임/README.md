## 문제

`N x N` 크기의 격자 형태 게임판이 있고, 각 칸에는 인형이 들어 있거나 비어 있습니다.
크레인을 움직여 인형을 뽑아 하나의 바구니에 쌓아 넣는 인형뽑기 게임을 진행합니다.

규칙은 다음과 같습니다.

1. `board` 는 `N x N` 2차원 배열입니다. `board[i][j]` 값이 `0` 이면 그 칸은 **비어 있고**, `1` 이상의 정수이면 그 값에 해당하는 **인형**이 놓여 있습니다.
2. 크레인은 한 번에 하나의 **열(column)** 위에서 작동합니다. `moves` 의 각 원소는 크레인을 작동시킬 열의 번호(**1-indexed**, 즉 가장 왼쪽 열이 1)입니다.
3. 어떤 열에서 크레인을 작동시키면, 그 열에서 **가장 위에 있는(행 번호가 가장 작은) 인형 하나**를 집어 바구니에 넣습니다. 집은 자리는 비게 됩니다.
   - 그 열에 인형이 하나도 없으면(모두 0이면) 아무 일도 일어나지 않습니다.
4. 바구니에 인형을 넣을 때, **방금 넣은 인형과 바로 아래(직전에 넣은) 인형이 같은 종류**라면 두 인형은 **터져서 사라집니다**.
5. 이렇게 터져서 사라진 인형의 **총 개수**를 반환합니다.

`board`(게임판 상태)와 `moves`(크레인을 작동시킬 열 번호 순서)가 주어질 때, 터뜨려 사라진 인형의 총 개수를 반환하세요.

## 제약 조건

- `board` 는 `N x N` 정사각 2차원 배열이며, `5 ≤ N ≤ 30` 입니다.
- `board` 의 각 원소는 0 이상 100 이하의 정수입니다. `0` 은 빈 칸, 그 외 값은 인형의 종류를 의미합니다.
- `moves` 배열의 길이는 1 이상 1,000 이하입니다.
- `moves` 의 각 원소는 1 이상 `N` 이하의 정수(크레인을 작동시킬 열 번호, 1-indexed)입니다.

## 입출력 예시

| board | moves | 반환값 |
|-------|-------|--------|
| `[[0,0,0,0,0],[0,0,1,0,3],[0,2,5,0,1],[4,2,4,4,2],[3,5,1,3,1]]` | `[1,5,3,5,1,2,1,4]` | `4` |
| `[[0,0,0],[0,0,0],[1,1,0]]` | `[1,2,1,2]` | `2` |

두 번째 예시 설명:
- 열 1 작동 → 인형 `1` 을 바구니에 넣음(바구니: `[1]`).
- 열 2 작동 → 인형 `1` 을 넣음. 직전 인형과 같아 둘 다 터짐(바구니: `[]`, 터진 개수 2).
- 열 1, 열 2 에는 더 이상 인형이 없어 아무 일도 없음. 최종 터진 인형 수 `2`.

## 문제

아래와 같이 3 x 4 배치의 전화 키패드가 있습니다.

```
[ 1 ][ 2 ][ 3 ]
[ 4 ][ 5 ][ 6 ]
[ 7 ][ 8 ][ 9 ]
[ * ][ 0 ][ # ]
```

이 키패드를 왼손과 오른손 두 엄지손가락만으로 누른다고 할 때, 다음 규칙에 따라 각 숫자를 누를 손을 정합니다.

1. 시작할 때 왼손 엄지손가락은 `*` 위치, 오른손 엄지손가락은 `#` 위치에서 시작합니다.
2. 숫자를 하나씩 순서대로 누르며, 손가락은 누른 자리로 이동합니다.
3. **1, 4, 7** 은 항상 **왼손**으로 누릅니다.
4. **3, 6, 9** 는 항상 **오른손**으로 누릅니다.
5. **2, 5, 8, 0** 은 그 순간 두 손가락 중 **누를 숫자에 더 가까운 손**으로 누릅니다.
   - 거리는 키패드에서의 **좌표 맨해튼 거리**(행 차이의 절댓값 + 열 차이의 절댓값)로 계산합니다.
   - 만약 두 손가락에서 누를 숫자까지의 거리가 **같다면**, 오른손잡이(`hand == "R"`)는 **오른손**, 왼손잡이(`hand == "L"`)는 **왼손**으로 누릅니다.

순서대로 누를 번호가 담긴 배열 `numbers` 와 주로 사용하는 손을 나타내는 문자열 `hand`(`"right"` 또는 `"left"`)가 주어질 때, 각 번호를 어느 손으로 눌렀는지를 순서대로 이어붙인 문자열을 반환하세요. 왼손으로 눌렀으면 `"L"`, 오른손으로 눌렀으면 `"R"` 을 사용합니다.

## 제약 조건

- `numbers` 배열의 길이는 1 이상 1,000 이하입니다.
- `numbers` 배열의 각 원소는 0 이상 9 이하의 정수입니다.
- `hand` 는 `"right"` 또는 `"left"` 이며, 각각 오른손잡이·왼손잡이임을 나타냅니다.
- 반환하는 문자열의 길이는 `numbers` 배열의 길이와 같습니다.

## 입출력 예시

| numbers | hand | 반환값 |
|---------|------|--------|
| `[1, 3, 4, 5, 8, 2, 1, 4, 5, 9, 5]` | `"right"` | `"LRLLLRLLRRL"` |
| `[7, 0, 8, 2, 8, 3, 1, 5, 7, 6, 2]` | `"left"` | `"LRLLRRLLLRR"` |
| `[2, 5, 0]` | `"right"` | `"RRL"` |
| `[2, 5, 0]` | `"left"` | `"LLR"` |

세 번째·네 번째 예시 설명(같은 입력 `[2, 5, 0]`, hand만 다름):
- `2` 는 (행 0, 열 1). 시작 시 왼손은 `*`=(3, 0)으로 거리 `3+1=4`, 오른손은 `#`=(3, 2)로 거리 `3+1=4` → **동점**. 오른손잡이면 R, 왼손잡이면 L.
- `5` 는 (1, 1). 오른손잡이 경우 직전에 오른손이 `2`=(0, 1)에 있어 거리 1, 왼손은 `*`=(3, 0)로 거리 3 → 오른손 R. 왼손잡이 경우 왼손이 `2`에 있어 거리 1 → 왼손 L.
- `0` 은 (3, 1). 오른손잡이 경우 오른손이 `5`=(1, 1)로 거리 2, 왼손이 `*`=(3, 0)로 거리 1 → 왼손 L. 왼손잡이 경우 왼손이 `5`로 거리 2, 오른손이 `#`=(3, 2)로 거리 1 → 오른손 R.
- 따라서 오른손잡이는 `"RRL"`, 왼손잡이는 `"LLR"`.

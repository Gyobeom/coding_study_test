## 문제

배열 `array`와, 여러 개의 명령이 담긴 배열 `commands`가 주어집니다.
각 명령은 `[i, j, k]` 세 정수로 이루어져 있으며, 다음 절차를 따라 하나의 값을 만들어 냅니다.

1. `array`의 **i번째부터 j번째까지**(둘 다 포함, **1부터 시작**하는 위치 기준)를 잘라냅니다.
2. 잘라낸 부분 배열을 **오름차순으로 정렬**합니다.
3. 정렬된 결과에서 **k번째** 값(역시 1부터 시작하는 위치)을 고릅니다.

각 명령에 대해 이렇게 구한 값을 **명령이 주어진 순서대로** 배열에 담아 반환하세요.

예를 들어 `array = [1, 5, 2, 6, 3, 7, 4]`, 명령이 `[2, 5, 3]`이라면
2번째부터 5번째까지 자른 `[5, 2, 6, 3]`을 정렬하면 `[2, 3, 5, 6]`이고, 그중 3번째 값은 `5`입니다.

## 제약 조건

- `array`의 길이는 1 이상 100 이하입니다.
- `array`의 각 원소는 1 이상 100 이하입니다.
- `commands`의 길이는 1 이상 50 이하입니다.
- `commands`의 각 원소는 길이가 3인 배열 `[i, j, k]`입니다.
  - `1 ≤ i ≤ j ≤ (array의 길이)`
  - `1 ≤ k ≤ (j - i + 1)`
- `i`, `j`, `k`는 모두 **1부터 시작하는** 위치를 의미합니다.

## 입출력 예시

| array | commands | 반환값 |
|-------|----------|--------|
| `[1, 5, 2, 6, 3, 7, 4]` | `[[2, 5, 3], [4, 4, 1], [1, 7, 3]]` | `[5, 6, 3]` |
| `[9, 8, 7, 6, 5]` | `[[1, 5, 1], [1, 5, 5]]` | `[5, 9]` |

두 번째 예시 설명:
- `[1, 5, 1]`: 전체 `[9, 8, 7, 6, 5]`를 정렬하면 `[5, 6, 7, 8, 9]`, 1번째 값은 `5`.
- `[1, 5, 5]`: 같은 정렬 결과에서 5번째 값은 `9`.

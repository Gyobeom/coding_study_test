## 문제

노드가 `n`개인 트리가 **부모 배열** `parent`로 주어집니다.
`parent[i]`는 노드 `i`의 부모 노드 번호이며, **루트 노드**의 부모는 `-1`입니다.
노드 번호는 `0`부터 `n-1`까지입니다.

각 노드 `i`에 대해, **노드 `i`를 루트로 하는 서브트리에 속한 노드의 개수**(자기 자신 포함)를
구해서 **노드 번호 순서대로**(인덱스 `0`부터) 담은 배열을 반환하세요.

예를 들어 리프 노드의 서브트리 크기는 자기 자신 하나뿐이므로 `1`이고,
전체 트리의 루트는 모든 노드를 포함하므로 `n`입니다.

## 제약 조건

- `1 <= n <= 100,000`
- `parent`의 길이는 `n`이고, 정확히 하나의 원소만 `-1`(루트)입니다.
- 나머지 원소 `parent[i]`는 `0 <= parent[i] <= n-1` 범위의 유효한 부모 번호이며,
  주어진 구조는 항상 사이클 없는 트리를 이룹니다.

## 입출력 예시

| parent | 반환값 | 설명 |
|--------|--------|------|
| `[-1, 0, 0, 1, 1]` | `[5, 3, 1, 1, 1]` | 0=루트(전체5), 1의 자식 3·4 → 서브트리3, 2·3·4는 리프 |
| `[1, -1, 1]` | `[1, 3, 1]` | 1=루트(전체3), 0·2는 리프 |
| `[-1]` | `[1]` | 노드 1개(루트뿐) |
| `[-1, 0, 1, 2]` | `[4, 3, 2, 1]` | 일자 사슬 0→1→2→3 |

## 문제

양의 정수 배열 `nums`와 목표값 `target`이 주어집니다.

`nums`에서 원소를 **골라서**(각 인덱스는 최대 한 번만 사용) 그 합이 정확히 `target`이 되는 **부분집합의 개수**를 반환하세요.

값이 같더라도 **서로 다른 인덱스**에서 뽑았다면 다른 경우로 셉니다. 예를 들어 `nums = [1, 1]`에서 합이 `1`이 되는 경우는 첫 번째 `1`을 고르는 것과 두 번째 `1`을 고르는 것, 총 2가지입니다.

### 예시로 이해하기

```
nums = [1, 2, 3, 4, 5], target = 5
```

합이 5가 되는 부분집합: `{5}`, `{1,4}`, `{2,3}` → `3`

## 제약 조건

- `1 <= len(nums) <= 20`
- `1 <= nums[i] <= 1000`
- `1 <= target <= 20000`
- 원소는 각 인덱스당 최대 1번만 사용합니다(같은 값이 여러 인덱스에 있을 수 있음).
- 합이 `target`인 부분집합이 없으면 `0`을 반환합니다.

## 입출력 예시

| nums | target | 반환값 | 설명 |
|------|--------|--------|------|
| `[1,2,3,4,5]` | `5` | `3` | {5},{1,4},{2,3} |
| `[1,1]` | `1` | `2` | 서로 다른 인덱스 → 2가지 |
| `[2,4,6]` | `5` | `0` | 만들 수 없음 |
| `[3,3,3]` | `6` | `3` | 세 인덱스 중 2개 고르기 → 3가지 |

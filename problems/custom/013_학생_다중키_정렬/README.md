## 문제

학생들의 목록 `students`가 주어집니다. 각 원소는 `[이름, 점수]` 형태이며
`이름`은 문자열, `점수`는 정수입니다.

학생들을 **점수 내림차순**으로 정렬하되, **점수가 같으면 이름 오름차순(사전순)** 으로 정렬합니다.
정렬한 뒤 **이름만** 순서대로 담은 배열을 반환하세요.

## 제약 조건

- `0 <= len(students) <= 100,000`
- 각 원소는 `[이름, 점수]` 이고 `이름`은 소문자 영어로 된 문자열(길이 `1`~`20`), `점수`는 정수입니다.
- 점수 범위: `-1,000,000 <= 점수 <= 1,000,000`
- 이름은 서로 중복될 수 있습니다.

## 입출력 예시

| students | 반환값 | 설명 |
|----------|--------|------|
| `[["alice",90],["bob",85],["carol",90]]` | `["alice","carol","bob"]` | 90(alice,carol) → 85(bob), 90 동점은 이름순 |
| `[["tom",70],["amy",70],["zoe",95]]` | `["zoe","amy","tom"]` | 95 먼저, 70 동점은 amy<tom |
| `[]` | `[]` | 빈 입력 |
| `[["kim",50]]` | `["kim"]` | 한 명 |

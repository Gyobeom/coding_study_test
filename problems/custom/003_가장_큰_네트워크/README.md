## 문제

컴퓨터 `n`대가 있고, 어떤 컴퓨터끼리는 연결되어 있습니다.
직접·간접으로 이어진 컴퓨터들은 하나의 **네트워크**로 봅니다(A–B, B–C가 연결이면 A와 C도 같은 네트워크).

컴퓨터의 연결 정보가 담긴 `n × n` 행렬 `computers`가 주어질 때,
**가장 큰 네트워크에 속한 컴퓨터의 수**를 반환하세요.

- `computers[i][j] == 1` 이면 컴퓨터 `i`와 `j`가 직접 연결.
- `computers[i][i] == 1`, `computers[i][j] == computers[j][i]`.

### 예시로 이해하기

```
n = 3
computers = [[1, 1, 0],
             [1, 1, 0],
             [0, 0, 1]]
```

- 네트워크 `{0, 1}` → 컴퓨터 2대
- 네트워크 `{2}` → 컴퓨터 1대

→ 가장 큰 네트워크의 크기 = **2**

## 제약 조건

- `1 <= n <= 200`
- `computers`는 `n × n` 행렬이고 각 원소는 `0` 또는 `1`
- `computers[i][i] == 1`, `computers[i][j] == computers[j][i]`
- 컴퓨터는 항상 1대 이상이므로 답은 최소 `1`입니다.

## 입출력 예시

| n | computers | 반환값 | 설명 |
|---|-----------|--------|------|
| 3 | `[[1,1,0],[1,1,0],[0,0,1]]` | `2` | {0,1}=2 vs {2}=1 → 2 |
| 3 | `[[1,1,0],[1,1,1],[0,1,1]]` | `3` | 전부 한 네트워크 → 3 |
| 2 | `[[1,0],[0,1]]` | `1` | 각자 1대씩 → 최대 1 |

## 힌트 (네트워크 개수 → 가장 큰 네트워크 크기)

이건 두 가지를 **합치는** 문제입니다. 이미 각각은 풀어봤습니다.

- **인접 행렬에서 이웃 찾기** = `네트워크`(예제)에서 한 것: `for j in range(n): if computers[i][j] == 1 and not visited[j]: ...`
- **dfs가 "크기(칸 수)"를 값으로 반환** = `가장 큰 섬`에서 한 것: `size = 1 + 이웃들 dfs 합`, 바깥에서 `best = max(best, dfs(...))`

즉 **격자 → 인접 행렬** 로 이웃 찾는 방식만 바꾸고, `가장 큰 섬`의 **반환형 + max 갱신** 구조를 그대로 얹으면 됩니다.

| | 가장 큰 섬 (격자) | 이번 문제 (인접 행렬) |
|---|---|---|
| 이웃 순회 | `for dr,dc in (상하좌우)` | `for j in range(n)` |
| 이웃 판정 | 범위 안 & `grid[nr][nc]==1` | `computers[i][j]==1` & `not visited[j]` |
| 방문 표시 | `grid[r][c]=0` | `visited[i]=True` |
| dfs 반환 | `1 + 사방 dfs 합` | `1 + 이웃 dfs 합` |
| 답 | `max(best, dfs(r,c))` | `max(best, dfs(i))` |

> ⚠️ 방문 표시는 `computers`를 덮어쓰지 말고 **별도 `visited` 리스트**를 쓰는 편이 깔끔합니다.
> `visited[i]=True`를 **dfs 진입 직후**에 해줘야 무한 재귀를 막습니다(자기 자신 `computers[i][i]==1` 때문).

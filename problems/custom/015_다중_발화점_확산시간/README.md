# 다중 발화점 확산 시간

- **분류**: 그래프 / BFS (다중 시작점)

## 문제

`R × C` 크기의 격자 `grid`가 주어집니다. 각 칸의 값은 다음 중 하나입니다.

- `0` : 빈 칸(확산이 지나갈 수 없는 벽)
- `1` : 아직 젖지 않은 칸
- `2` : 발화점(시작점). 여러 개일 수 있습니다.

매 시간 단위마다 모든 `2`는 **상하좌우로 인접한** `1` 칸으로 동시에 번져 그 칸을 `2`로 바꿉니다.
`0`(벽)으로는 번지지 않습니다.

**모든 `1` 칸이 젖는 데 걸리는 최소 시간**을 반환하세요.
처음부터 `1`이 하나도 없으면 `0`을 반환하고,
아무리 시간이 지나도 도달할 수 없는 `1`이 남으면 `-1`을 반환합니다.

## 제약 조건

- `1 <= R, C <= 1,000`
- `grid[i][j]`는 `0`, `1`, `2` 중 하나입니다.
- `2`(발화점)는 `0`개 이상일 수 있습니다. 발화점이 없고 `1`이 남아 있으면 `-1`입니다.
- 이동은 상하좌우 4방향만 가능합니다(대각선 불가).

## 입출력 예시

| grid | 반환값 | 설명 |
|------|--------|------|
| `[[2,1,1],[1,1,0],[0,1,1]]` | `4` | 왼쪽 위 2에서 번져 마지막 칸까지 4단계 |
| `[[2,1,1],[0,1,1],[1,0,1]]` | `-1` | 왼쪽 아래 `1`은 벽에 막혀 도달 불가 |
| `[[0,2]]` | `0` | 젖을 `1`이 없음 |
| `[[2,1,1,1,1]]` | `4` | 한 줄에서 4칸 → 4 |
| `[[2,2],[1,1]]` | `1` | 두 발화점에서 동시에 → 1 |

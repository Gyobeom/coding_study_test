## 문제

`0`과 `1`로 이루어진 2차원 격자 `grid`가 주어집니다. `1`은 땅, `0`은 물입니다.

땅으로 이루어진 각 칸은 상하좌우 네 변을 가집니다. 어떤 변이 **격자 바깥(경계)에 닿거나** 그 방향의 이웃 칸이 **물(`0`)**이면, 그 변은 섬의 둘레의 일부입니다.

격자 전체에서 모든 땅 칸의 **둘레(바깥에 노출된 변)의 총합**을 반환하세요.

### 예시로 이해하기

```
grid = [[0, 1, 0],
        [1, 1, 1],
        [0, 1, 0]]
```

가운데 십자 모양(땅 5칸)의 바깥 둘레는 총 `12`입니다.

## 제약 조건

- `1 <= len(grid) <= 100` (행 수)
- `1 <= len(grid[0]) <= 100` (열 수), 모든 행의 길이는 같습니다.
- `grid[i][j]`는 `0` 또는 `1`.
- 땅이 하나도 없으면 둘레는 `0`.

## 입출력 예시

| grid | 반환값 | 설명 |
|------|--------|------|
| `[[0,1,0],[1,1,1],[0,1,0]]` | `12` | 십자 5칸의 둘레 |
| `[[1]]` | `4` | 단일 칸은 사방이 바깥 → 4 |
| `[[1,1],[1,1]]` | `8` | 2×2 꽉 찬 블록의 둘레 |
| `[[0,0],[0,0]]` | `0` | 땅 없음 → 0 |

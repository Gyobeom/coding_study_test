## 문제

하나의 회의실에 배정하려는 회의 목록 `meetings`가 주어집니다. 각 회의는 `[시작시각, 끝시각]`으로 표현됩니다.

한 회의실은 같은 시간에 하나의 회의만 열 수 있습니다. **한 회의가 끝나는 시각과 다음 회의가 시작하는 시각이 같은 것은 겹치지 않는 것으로 봅니다**(끝나자마자 바로 다음 회의 시작 가능).

서로 겹치지 않게 배정할 수 있는 회의의 **최대 개수**를 반환하세요.

### 예시로 이해하기

```
meetings = [[1, 4], [3, 5], [0, 6], [5, 7], [3, 8], [5, 9], [6, 10], [8, 11], [8, 12], [2, 13], [12, 14]]
```

끝나는 시각이 빠른 회의부터 고르면 `[1,4] → [5,7] → [8,11] → [12,14]` 등으로 최대 `4`개를 배정할 수 있습니다. → `4`

## 제약 조건

- `0 <= len(meetings) <= 100000`
- 각 회의는 `[시작, 끝]`이며 `0 <= 시작 <= 끝 <= 10^9`.
- 시작과 끝이 같은 회의(길이 0)도 있을 수 있습니다.
- 회의가 하나도 없으면 `0`을 반환합니다.

## 입출력 예시

| meetings | 반환값 | 설명 |
|----------|--------|------|
| `[[1,4],[3,5],[0,6],[5,7],[3,8],[5,9],[6,10],[8,11],[8,12],[2,13],[12,14]]` | `4` | 최대 4개 |
| `[[0,1],[1,2],[2,3]]` | `3` | 끝=시작 접함, 전부 배정 |
| `[[0,10],[1,2],[3,4]]` | `2` | 긴 회의 대신 짧은 2개 |
| `[]` | `0` | 회의 없음 |

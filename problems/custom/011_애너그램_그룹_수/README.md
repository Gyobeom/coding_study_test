## 문제

소문자 영어로 된 문자열 배열 `words`가 주어집니다.
두 문자열이 **같은 글자들을 같은 개수만큼** 가지고 있어(순서만 다르게 재배열하면 서로 같아짐) 애너그램이면
같은 그룹에 속합니다. 예를 들어 `"eat"`, `"tea"`, `"ate"`는 모두 같은 그룹입니다.

`words`를 애너그램끼리 묶었을 때 **그룹의 개수**를 반환하세요.

## 제약 조건

- `1 <= len(words) <= 100,000`
- 각 문자열은 소문자 영어(`a`~`z`)로만 이루어지고, 길이는 `1` 이상 `100` 이하입니다.
- 배열에 같은 문자열이 중복해서 들어올 수 있습니다(중복도 같은 그룹으로 묶입니다).

## 입출력 예시

| words | 반환값 | 설명 |
|-------|--------|------|
| `["eat","tea","tan","ate","nat","bat"]` | `3` | `{eat,tea,ate}`, `{tan,nat}`, `{bat}` → 3 |
| `["abc","bca","cab","xyz"]` | `2` | `{abc,bca,cab}`, `{xyz}` → 2 |
| `["a"]` | `1` | 문자열 1개 → 1 |
| `["ab","ab","ba"]` | `1` | 전부 같은 애너그램 → 1 |

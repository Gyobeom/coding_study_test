아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

단어들이 주어지고, 각 단어들의 순서가 다르더라도 동일한 알파벳을 보유하면 같은 묶음으로 치기에, 소문자로 정렬하고, 이후에 이미 출현한 단어인지 확인하기 위해서 해시값으로 해당 단어를 등록해서 처리 하였음.

## 시행착오 / 막혔던 점

문자열을 정렬하는 방법을 알지 못해서 검색하였음. sorted(word) 후 리스트로 반횐 된 값을 ''.join을 통해서 문자열 처리함. hash에서 값을 찾을 때, 없는 값에 한해서 에러가 반환되지 않도록, get을 사용해서 값을 찾고, 없다면 get(찾을 값, 초기값) 초기값으로 설정할 수 있음, 여기에 각 단어의 수를 증가시키고 싶다면 get(찾을 값, 초기값) + 1 이런식으로 처리

## 문제

정수 배열 `numbers`와 정수 `target`이 주어진다. 배열 안에서 **서로 다른 두 원소를 골라
그 합이 `target`이 되는 경우**, 두 원소의 **인덱스 쌍**을 오름차순 리스트 `[i, j]` (i < j) 로 반환하라.
정답이 되는 쌍은 항상 **정확히 하나** 존재한다고 가정한다.

## 제약 조건

- `2 <= len(numbers) <= 10,000`
- `-10^9 <= numbers[i] <= 10^9`
- 같은 원소를 두 번 사용할 수 없다(인덱스가 달라야 한다).
- 정답 쌍은 유일하다.

## 입출력 예시

| numbers | target | 반환값 |
|---------|--------|--------|
| [2, 7, 11, 15] | 9 | [0, 1] |
| [3, 2, 4] | 6 | [1, 2] |
| [3, 3] | 6 | [0, 1] |

## 문제

정수 배열 `nums`와 정수 `limit`이 주어집니다.
`nums`의 **부분집합**(원소를 아무것도 안 고르는 것부터 전부 고르는 것까지) 중에서,
**원소들의 합이 `limit` 이하**가 되는 부분집합을 고를 때 얻을 수 있는 **가장 큰 합**을 반환하세요.

아무 원소도 고르지 않으면 합은 `0`입니다. 따라서 `limit >= 0`이면 답은 최소 `0`입니다.
만약 모든(비어 있지 않은) 부분집합의 합이 `limit`을 초과한다면 빈 부분집합을 골라 `0`을 반환합니다.

## 제약 조건

- `0 <= len(nums) <= 20`
- 각 원소는 정수이며 `-1,000 <= nums[i] <= 1,000` (음수 포함 가능)
- `-1,000 <= limit <= 1,000,000`
- 부분집합의 합이 `limit`을 넘지 않는 한도에서 최대가 되는 값을 구합니다.
- `limit < 0`이면 빈 부분집합(합 `0`)도 조건을 못 맞출 수 있습니다. 이때는 조건을 만족하는 부분집합 중 최대 합을 반환합니다(음수 원소로 만들 수 있으면 그 값).

## 입출력 예시

| nums | limit | 반환값 | 설명 |
|------|-------|--------|------|
| `[3, 5, 8]` | `10` | `8` | `{3,5}`=8 ≤ 10, `{8}`=8, `{3,8}`=11 초과 → 8 |
| `[1, 2, 3]` | `100` | `6` | 전부 골라도 6 ≤ 100 → 6 |
| `[5, 6, 7]` | `4` | `0` | 어떤 원소도 4 이하 불가 → 빈 집합 0 |
| `[-2, -3]` | `-1` | `-2` | `{-2}`=-2 ≤ -1, `{-3}`=-3 → 최대는 -2 |
| `[]` | `5` | `0` | 빈 배열 → 0 |

## 문제

물건들의 무게가 순서대로 담긴 배열 `weights`와 트럭 대수 `D`가 주어집니다.

물건은 **배열 순서대로** 트럭에 싣습니다. 한 트럭에 물건을 **연속으로** 담다가, 지금 담으려는 물건을 더하면 트럭의 **적재 용량**을 넘게 되는 경우 그 트럭은 출발하고 다음 트럭에 담기 시작합니다(물건을 쪼개거나 순서를 바꿀 수 없습니다).

모든 물건을 트럭 **`D`대 이내**로 전부 나를 수 있는 **최소 적재 용량**을 반환하세요.

### 예시로 이해하기

```
weights = [1, 2, 3, 4, 5], D = 2
```

용량이 `9`면: 트럭1에 `1,2,3`(합 6)을 싣고 `4`를 더하면 10>9라 트럭1 출발, 트럭2에 `4,5`(합 9). 2대로 완료. 용량 `8`이면 3대가 필요하므로, 최소 용량은 `9`. → `9`

## 제약 조건

- `1 <= len(weights) <= 100000`
- `1 <= D <= len(weights)`
- `1 <= weights[i] <= 10000`
- 용량은 개별 물건 하나는 반드시 실을 수 있어야 하므로 최소 `max(weights)` 이상입니다.

## 입출력 예시

| weights | D | 반환값 | 설명 |
|---------|---|--------|------|
| `[1,2,3,4,5]` | `2` | `9` | 8이면 3대, 9면 2대 |
| `[1,2,3,4,5]` | `5` | `5` | 트럭 5대면 최대 물건 하나씩 → max=5 |
| `[1,2,3,4,5]` | `1` | `15` | 트럭 1대에 전부 → 합=15 |
| `[10,10,10]` | `3` | `10` | 각 트럭에 하나씩 → 10 |

## 문제

정수 배열 `nums`와 정수 `k`가 주어집니다. `nums`를 **오름차순으로 정렬했을 때 `k`번째에 오는 값**(즉 `k`번째로 작은 값)을 반환하세요. `k`는 1부터 셉니다(가장 작은 값이 1번째).

같은 값이 여러 번 나올 수 있으며, 중복도 각각 하나의 원소로 셉니다.

### 예시로 이해하기

```
nums = [7, 10, 4, 3, 20, 15], k = 3
```

정렬하면 `[3, 4, 7, 10, 15, 20]`, 3번째 값은 `7`. → `7`

## 제약 조건

- `1 <= len(nums) <= 100000`
- `1 <= k <= len(nums)`
- `nums`의 각 원소는 `-10^9 <= nums[i] <= 10^9`.
- 중복 값이 있을 수 있습니다.

## 입출력 예시

| nums | k | 반환값 | 설명 |
|------|---|--------|------|
| `[7,10,4,3,20,15]` | `3` | `7` | 정렬 시 3번째 |
| `[1,1,1,1]` | `2` | `1` | 모두 같은 값 |
| `[5]` | `1` | `5` | 원소 하나 |
| `[9,8,7,6,5]` | `5` | `9` | 가장 큰 값(마지막) |

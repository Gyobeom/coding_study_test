## 문제

여는 괄호 `'('` 와 닫는 괄호 `')'` 로만 이루어진 문자열 `s`가 주어집니다.
`s`는 항상 **올바른 괄호 문자열**임이 보장됩니다(모든 여는 괄호가 짝이 맞고 순서가 올바름).

괄호의 **최대 중첩 깊이**를 반환하세요.
중첩 깊이란 어떤 위치에서 그 자리를 감싸고 있는 여는 괄호의 개수 중 가장 큰 값입니다.
예를 들어 `"(())"`는 안쪽 `()`가 2겹으로 감싸여 있으므로 최대 깊이는 `2`입니다.
빈 문자열은 괄호가 없으므로 깊이 `0`입니다.

## 제약 조건

- `0 <= len(s) <= 100,000`
- `s`는 `'('` 와 `')'` 문자로만 구성됩니다(빈 문자열 가능).
- `s`는 항상 올바른 괄호 문자열입니다.

## 입출력 예시

| s | 반환값 | 설명 |
|---|--------|------|
| `"(())"` | `2` | 바깥·안쪽 2겹 |
| `"()()"` | `1` | 나란히 1겹씩 → 최대 1 |
| `"((()))"` | `3` | 3겹 |
| `""` | `0` | 괄호 없음 |
| `"(()(()))"` | `3` | 가장 깊은 곳이 3겹 |

# 풀이노트 — 괄호 최대 깊이

아래 항목은 가이드일 뿐, 남기고 싶은 만큼만 쓰면 된다.

## 접근 방법

무조건 쌓인 괄호들이 나온다고 했으니, 괄호의 시작 괄호를 기준으로 list에 넣어서 처리 하는 것으로 생각함.

## 시행착오 / 막혔던 점

최대 중첩 괄호를 반환 했어야 하는데, list / cnt / max_cnt 3개를 다 사용하면서 복잡하게 로직을 생각했었음. 시작 괄호를 만났을 때마다 list에 추가하고, max_cnt를 구하게되면 애초에 결합 괄호도 미리 처리가 돼서 내부 괄호가 종료되더라도 별도의 로직 처리 없이 max_cnt를 구할 수 있었음.
